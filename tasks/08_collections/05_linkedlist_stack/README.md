## JAVA_08_05. Стек на LinkedList

### Задание
| Java_08_05 ||
| ------ | ------- |
| **Темы:** | `Deque`, `LinkedList`, LIFO, `push`/`pop`/`peek`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Реализуй обработку команд для стека (LIFO — последний пришёл, первый вышел).

Первая строка — число команд `N`. Далее идут `N` команд:

| Команда | Действие | Что вывести |
| --- | --- | --- |
| `push x` | положить `x` на вершину | ничего |
| `pop` | снять верхний элемент | его значение или `empty` |
| `peek` | посмотреть верхний | его значение или `empty` |
| `size` | размер стека | число |

Каждый вывод — на отдельной строке.

Используй `Deque<Integer>` с реализацией `LinkedList`:

```java
Deque<Integer> stack = new LinkedList<>();
stack.push(5);        // положить на вершину
int top = stack.pop();// снять с вершины
int seen = stack.peek(); // посмотреть, не снимая
boolean empty = stack.isEmpty();
```

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 4<br>push 1 push 2 pop size | 2<br>1 |
| 3<br>peek push 5 peek | empty<br>5 |
| 2<br>push 7 pop | 7 |
