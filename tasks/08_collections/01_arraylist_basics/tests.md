# JAVA_08_01. ArrayList: основы — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `3` + `1 2 3` | `3\n1 2 3\n6\n` | Размер, элементы, сумма |
| `1` + `5` | `1\n5\n5\n` | Один элемент |
| `4` + `-1 0 1 2` | `4\n-1 0 1 2\n2\n` | Сумма с отрицательным |
| `2` + `10 20` | `2\n10 20\n30\n` | Два элемента |

## Крайние случаи

- **Один элемент** — `size()` равен 1, сумма совпадает с элементом.
- **Отрицательные числа** — суммируются как обычно.
- **Порядок** — `ArrayList` сохраняет порядок добавления.
