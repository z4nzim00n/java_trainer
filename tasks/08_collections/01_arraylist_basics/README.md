## JAVA_08_01. ArrayList: основы

### Задание
| Java_08_01 ||
| ------ | ------- |

| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай `N`, затем `N` целых чисел в `ArrayList<Integer>`. Выведи три строки:

1. количество элементов;
2. сами элементы через пробел;
3. их сумму.

```java
List<Integer> list = new ArrayList<>();
for (int i = 0; i < n; i++) {
    list.add(sc.nextInt());
}
```

Обрати внимание: в дженериках нельзя указать примитив `int`, только класс-обёртку `Integer`. Java автоматически «упаковывает» `int` в `Integer` при `add` и «распаковывает» при чтении — это называется автоупаковкой (autoboxing).

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |

| 1<br>5 | 1<br>5<br>5 |
| 4<br>-1 0 1 2 | 4<br>-1 0 1 2<br>2 |
