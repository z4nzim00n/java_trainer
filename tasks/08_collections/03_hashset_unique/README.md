## JAVA_08_03. Уникальные значения через HashSet

### Задание
| Java_08_03 ||
| ------ | ------- |
| **Темы:** | `HashSet`, уникальность, `add`, сортировка результата. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай `N`, затем `N` целых чисел. Выведи:

1. количество **различных** чисел;
2. сами различные числа **в порядке возрастания**, через пробел.

```java
Set<Integer> set = new HashSet<>();
for (int i = 0; i < n; i++) {
    set.add(sc.nextInt());
}
System.out.println(set.size());
List<Integer> sorted = new ArrayList<>(set);
Collections.sort(sorted);
```

`HashSet` автоматически отбрасывает повторы: повторный `add` того же значения возвращает `false` и ничего не меняет.

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>1 2 2 3 1 | 3<br>1 2 3 |
| 3<br>5 5 5 | 1<br>5 |
| 4<br>-1 0 -1 0 | 2<br>-1 0 |
