# JAVA_08_03. Уникальные значения через HashSet — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `5` + `1 2 2 3 1` | `3\n1 2 3\n` | Три уникальных |
| `3` + `5 5 5` | `1\n5\n` | Одно уникальное |
| `4` + `-1 0 -1 0` | `2\n-1 0\n` | Отрицательное и ноль |
| `5` + `5 4 3 2 1` | `5\n1 2 3 4 5\n` | Сортировка после Set |

## Крайние случаи

- **Все элементы одинаковы** — в множестве один элемент.
- **Все элементы различны** — количество совпадает с N.
- **Отрицательные числа** — сортируются по возрастанию.
- **Порядок ввода** — на результат не влияет.
