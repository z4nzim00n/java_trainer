## JAVA_08_06. Удаление через Iterator

### Задание
| Java_08_06 ||
| ------ | ------- |
| **Темы:** | `Iterator`, `remove()`, `ConcurrentModificationException`. |
| **Файл решения:** | Main.java |
| **Входные данные** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай `N`, затем `N` целых чисел в `ArrayList<Integer>`. Удали из списка **все чётные** числа и выведи оставшиеся через пробел в одной строке. Если не осталось ничего, выведи `empty`.

Удалять во время обхода через `for-each` нельзя — будет исключение. Правильный способ — `Iterator`:

```java
Iterator<Integer> it = list.iterator();
while (it.hasNext()) {
    int value = it.next();
    if (value % 2 == 0) {
        it.remove();
    }
}
```

`it.remove()` удаляет последний элемент, возвращённый `next()`, и корректно обновляет внутреннее состояние итератора.

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>1 2 3 4 5 | 1 3 5 |
| 4<br>2 4 6 8 | empty |
| 3<br>1 3 5 | 1 3 5 |
