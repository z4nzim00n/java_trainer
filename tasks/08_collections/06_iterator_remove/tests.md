# JAVA_08_06. Удаление через Iterator — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `5` + `1 2 3 4 5` | `1 3 5\n` | Удалены 2 и 4 |
| `4` + `2 4 6 8` | `empty\n` | Всё чётное |
| `3` + `1 3 5` | `1 3 5\n` | Ничего не удалено |
| `2` + `0 1` | `1\n` | Ноль тоже чётный |

## Крайние случаи

- **Все чётные** — список пуст, печатается `empty`.
- **Ни одного чётного** — список не меняется.
- **Ноль** — чётное число, удаляется.
- **Отрицательные чётные** (`-2`) — тоже удаляются: `-2 % 2 == 0`.
