## JAVA_06_05. Убрать лишние пробелы

### Задание
| Java_06_05 ||
| ------ | ------- |
| **Темы:** | `trim()`, `replaceAll()`, регулярные выражения, неизменяемость строк. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Считай одну строку и приведи её к аккуратному виду:

- убери пробелы в начале и в конце;
- замени каждую группу пробелов внутри на **один** пробел.

Выведи результат с переносом строки в конце. Если после обработки строка пустая, выведи просто пустую строку.

```java
String line = sc.nextLine().trim();
if (line.isEmpty()) {
    System.out.println();
} else {
    System.out.println(line.replaceAll("\\s+", " "));
}
```

`replaceAll("\\s+", " ")` заменяет каждое вхождение «одного или нескольких пробельных символов» на одиночный пробел.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `  hello   world  ` | `hello world` |
| `a  b` | `a b` |
| `one` | `one` |
| (пустая строка) | (пустая строка) |
