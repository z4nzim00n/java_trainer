# Разбор задания

## Две операции

| Операция | Метод |
| --- | --- |
| убрать пробелы по краям | `trim()` |
| сжать внутренние пробелы | `replaceAll("\\s+", " ")` |

## replaceAll

```java
"a   b".replaceAll("\\s+", " ")   // "a b"
```

Первый аргумент — регулярное выражение, второй — замена. `\s` обозначает пробельный символ, `+` — «один или более». В строковом литерале Java обратная косая черта удваивается: `"\\s+"`.

Есть ещё `replace(" ", " ")`, который работает с обычными подстроками, а не с регулярными выражениями. Он не сожмёт группу пробелов: заменит каждый пробел по отдельности на пробел.

## Порядок операций

Сначала `trim()`, потом `replaceAll` — или наоборот, результат одинаковый. Но `trim()` до замены позволяет сразу проверить `isEmpty()` и красиво обработать пустой ввод.

Почему вообще нужна отдельная проверка? `"".replaceAll("\\s+", " ")` вернёт `""`, и `println` напечатает пустую строку с переводом — это правильный результат. Отдельная ветка нужна только для наглядности; можно обойтись и одной строкой:

```java
System.out.println(line.replaceAll("\\s+", " "));
```

## Неизменяемость

`trim()` и `replaceAll()` не меняют исходную строку, а возвращают новую:

```java
String s = "  a  b  ";
s.trim();                    // результат потерян
s = s.trim();                // правильно
```

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `replaceAll("\\s", " ")` без `+` | Каждый пробел заменяется на пробел — сжатия нет; но результат тот же |
| `replaceAll(" +", " ")` | Работает только для обычных пробелов, не для табов |
| Забыть `trim()` | Остаются пробелы по краям |
| `"\\s+"` без удвоения | Ошибка компиляции экранирования |
| `line.replaceAll(...)` без вывода | Изменения потеряны |
