# JAVA_06_05. Убрать лишние пробелы — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `  hello   world  ` | `hello world\n` | Пробелы по краям убраны, внутренние сжаты |
| `a  b` | `a b\n` | Два пробела → один |
| `one` | `one\n` | Менять нечего |
| `` (пустая строка) | `\n` | Пустая строка и один перевод |
| `     ` | `\n` | Только пробелы → пустая строка |

## Крайние случаи

- **Только пробелы** — после `trim()` пустая строка.
- **Один пробел между словами** — остаётся одним.
- **Много пробелов подряд** — сжимаются в один.
- **Пробелы по краям** — удаляются полностью.
