# Разбор задания

## Доступ к символам

```java
char c = line.charAt(i);   // i от 0 до length() - 1
```

`char` — 16-битный примитив, символ в одинарных кавычках: `'a'`, `'7'`, `' '`.

## Методы Character

| Метод | Для чего | Примеры |
| --- | --- | --- |
| `Character.isLetter(c)` | буква в любой письменности | `'a'`, `'Я'` |
| `Character.isDigit(c)` | десятичная цифра | `'0'`..`'9'` |
| `Character.isLetterOrDigit(c)` | буква **или** цифра | оба случая |
| `Character.toUpperCase(c)` | верхний регистр | `'a' → 'A'` |
| `Character.toLowerCase(c)` | нижний регистр | `'A' → 'a'` |

Это статические методы: вызываются через имя класса, а не через объект.

## Почему не сравнение с диапазонами

Можно написать `c >= 'a' && c <= 'z'`, и для ASCII это сработает. Но `isLetter` корректно работает и с кириллицей, и с другими алфавитами. Привычка использовать `Character` — хорошая.

## Счётчики

Обычные `int`, инициализированные нулём, инкрементируются в цикле:

```java
int letters = 0;
int digits = 0;
```

Один проход по строке — O(N).

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `line[i]` | У `String` нет индексации через `[]` |
| `Character.isLetter(line.charAt(i))` с `int` | Тип `char` приводится автоматически, это нормально |
| Считать пробелы буквами | `isLetter(' ')` равно `false` |
| `i <= line.length()` | `StringIndexOutOfBoundsException` |
| Считать цифры как буквы | В задаче нужны отдельные счётчики |
