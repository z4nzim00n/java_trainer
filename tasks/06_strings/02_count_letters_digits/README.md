## JAVA_06_02. Буквы и цифры

### Задание
| Java_06_02 ||
| ------ | ------- |
| **Темы:** | `String`, `charAt`, `char`, `Character.isLetter`, `Character.isDigit`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Считай одну строку целиком и посчитай, сколько в ней **букв** и сколько **цифр**. Все остальные символы (пробелы, знаки препинания) не считаются. Выведи два числа через пробел:

```text
<букв> <цифр>
```

Проходи по строке посимвольно и используй готовые методы класса `Character`:

```java
for (int i = 0; i < line.length(); i++) {
    char c = line.charAt(i);
    if (Character.isLetter(c)) {
        letters++;
    } else if (Character.isDigit(c)) {
        digits++;
    }
}
```

Гарантируется, что строка состоит из ASCII-символов.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| abc123 | 3 3 |
| Hello, World! | 10 0 |
| 2024 | 0 4 |
