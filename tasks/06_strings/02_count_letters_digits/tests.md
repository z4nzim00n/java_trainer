# JAVA_06_02. Буквы и цифры — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `abc123` | `3 3\n` | Три буквы, три цифры |
| `Hello, World!` | `10 0\n` | Пробелы, запятая и `!` не считаются |
| `2024` | `0 4\n` | Только цифры |
| `a1 b2 c3` | `3 3\n` | Пробелы игнорируются |
| `!@#` | `0 0\n` | Ни букв, ни цифр |

## Крайние случаи

- **Знаки препинания** — не относятся ни к одной категории.
- **Пробелы** — тоже не буквы и не цифры.
- **Смешанная строка** — счётчики независимы.
- **Пустая строка** — оба счётчика остаются нулями.
