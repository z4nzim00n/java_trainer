# JAVA_06_06. Развернуть строку — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `hello` | `olleh\n` | Обычный случай |
| `Java` | `avaJ\n` | Регистр сохраняется |
| `12345` | `54321\n` | Цифры тоже символы |
| `` (пустая строка) | `\n` | Пустая строка переворачивается в себя |
| `ab` | `ba\n` | Минимальная непустая строка |

## Крайние случаи

- **Пустая строка** — ответ тоже пустая строка.
- **Один символ** — не меняется.
- **Палиндром** (`level`) — разворот совпадает с исходной строкой.
- **Пробелы внутри** — переворачиваются как обычные символы.
