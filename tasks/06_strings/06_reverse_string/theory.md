# Разбор задания

## String и StringBuilder

| | `String` | `StringBuilder` |
| --- | --- | --- |
| Изменяемость | нет | да |
| Конкатенация в цикле | создаёт новые строки | дописывает в буфер |
| Метод `reverse()` | нет | есть |

`String` удобен для хранения готовых строк, `StringBuilder` — для сборки и изменения.

## Цепочка вызовов

```java
new StringBuilder(line).reverse().toString()
```

1. `new StringBuilder(line)` — копия строки в изменяемый буфер.
2. `.reverse()` — переворачивает буфер и возвращает **тот же** объект.
3. `.toString()` — новая неизменяемая строка.

## Альтернатива: цикл с конца

```java
StringBuilder sb = new StringBuilder();
for (int i = line.length() - 1; i >= 0; i--) {
    sb.append(line.charAt(i));
}
System.out.println(sb);
```

Результат тот же. Цикл полезен, когда нужно разворачивать не всю строку, а, например, только слова.

## Пустая строка

`new StringBuilder("").reverse().toString()` равно `""`. `println` напечатает пустую строку — корректно.

## Сложность

`reverse()` работает за O(N). Строка `StringBuilder` выделяет буфер с запасом, поэтому добавление символов обычно не перевыделяет память на каждом шаге.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `line.reverse()` | У `String` нет такого метода |
| Забыть `toString()` | `println(sb)` выведет содержимое, но тип останется `StringBuilder` |
| `new String(line).reverse()` | `String` неизменяем, `reverse` не существует |
| `i >= 0` в цикле с `charAt` | Корректно; ошибка — `i > 0`, теряется первый символ |
