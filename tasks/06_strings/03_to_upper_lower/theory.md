# Разбор задания

## Неизменяемость строк

`String` в Java **immutable**: после создания строку нельзя изменить. Любой «изменяющий» метод возвращает новый объект:

```java
String s = "Hello";
String upper = s.toUpperCase();   // "HELLO"
System.out.println(s);            // всё ещё "Hello"
```

Поэтому вызов `line.toUpperCase();` без сохранения результата или вывода ничего не делает — возвращённое значение просто теряется.

## Методы регистра

| Метод | Что делает |
| --- | --- |
| `toUpperCase()` | все буквы в верхний регистр |
| `toLowerCase()` | все буквы в нижний регистр |

Цифры, пробелы и знаки препинания не меняются: `"A1!"` → `"A1!"` / `"a1!"`.

## Локаль

По умолчанию методы используют локаль системы. В турецкой локали `"i".toUpperCase()` даёт `İ`, а не `I`. Чтобы поведение было предсказуемым, можно указать локаль явно:

```java
line.toUpperCase(Locale.ROOT)
```

Для ASCII-строк в русской локали результат совпадает с обычным вызовом, поэтому в решении достаточно `toUpperCase()`.

## Новая строка, а не изменение

```java
String s = "abc";
s.toUpperCase();          // результат потерян
System.out.println(s);    // abc

s = s.toUpperCase();      // так правильно — присвоили результат
System.out.println(s);    // ABC
```

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `line.toUpperCase();` без вывода | Ничего не печатается |
| Ожидать изменения `line` | Строка неизменяема |
| `line.toUpper()` | Такого метода нет: `toUpperCase` |
| Забыть вторую строку | Тест ждёт и верхний, и нижний регистр |
| Перепутать порядок | Сначала верхний, потом нижний |
