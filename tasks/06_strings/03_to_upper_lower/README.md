## JAVA_06_03. Верхний и нижний регистр

### Задание
| Java_06_03 ||
| ------ | ------- |
| **Темы:** | `String`, `toUpperCase()`, `toLowerCase()`, неизменяемость строк. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай одну строку целиком. Выведи её в **верхнем** регистре на первой строке и в **нижнем** регистре на второй.

```java
String line = sc.nextLine();
System.out.println(line.toUpperCase());
System.out.println(line.toLowerCase());
```

Оба метода возвращают **новую** строку: исходная `line` не меняется. Это важно понять про `String` в Java.

Гарантируется, что строка состоит из ASCII-символов.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Hello World | HELLO WORLD<br>hello world |
| java | JAVA<br>java |
| ABC | ABC<br>abc |
