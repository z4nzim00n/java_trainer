## JAVA_06_04. Количество слов

### Задание
| Java_06_04 ||
| ------ | ------- |
| **Темы:** | `trim()`, `isEmpty()`, `split()`, регулярные выражения. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Считай одну строку и посчитай количество **слов** в ней. Слова разделены одним или несколькими пробелами; пробелы в начале и конце строки не считаются словами. Пустая строка содержит `0` слов.

Выведи одно число с переносом строки.

Удобный приём — `trim()` и `split()`:

```java
String line = sc.nextLine().trim();
if (line.isEmpty()) {
    System.out.println(0);
} else {
    System.out.println(line.split("\\s+").length);
}
```

`"\\s+"` — регулярное выражение: «один или несколько пробельных символов». В Java-строке обратная косая черта удваивается, поэтому пишется `\\s`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| hello world | 2 |
| one two three | 3 |
| (пустая строка) | 0 |
