# Разбор задания

## trim()

`trim()` возвращает копию строки без пробельных символов в начале и конце:

```java
"  hello  ".trim()   // "hello"
```

Внутренние пробелы сохраняются. В Java 11+ есть `strip()`, который учитывает больше видов пробелов; в этом курсе (Java 8) используется `trim()`.

## split()

`split(regex)` разбивает строку по регулярному выражению и возвращает массив строк:

```java
"a b c".split(" ")      // ["a", "b", "c"]
"a  b".split(" ")       // ["a", "", "b"] — пустой элемент!
"a  b".split("\\s+")    // ["a", "b"]
```

Именно поэтому нужен `\\s+`, а не просто `" "`: несколько подряд идущих пробелов дадут пустые строки в массиве.

## Ловушка с пустой строкой

`"".split("\\s+")` возвращает массив из одного элемента `[""]` — длина 1, хотя слов ноль. Поэтому пустую строку обрабатываем отдельно:

```java
if (line.isEmpty()) {
    System.out.println(0);
}
```

## Регулярные выражения: минимум

| Запись | Значение |
| --- | --- |
| `\s` | пробельный символ (пробел, таб, перевод строки) |
| `+` | один или больше предыдущих |
| `\s+` | один или несколько пробельных символов |

В строковом литерале Java `\` экранируется, поэтому пишем `"\\s+"`.

## Сложность

`trim()` и `split()` создают новые строки и массив — O(N) по времени и памяти. Для одной строки это несущественно.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `split(" ")` | Несколько пробелов дают пустые элементы |
| Нет `trim()` | Пробелы в конце создают лишний пустой элемент |
| Нет проверки на пустую строку | Для `""` получается 1 вместо 0 |
| `split("\\s")` без `+` | Каждый пробел — отдельный разделитель |
| `"\\s+"` без второго `\` в исходнике | Ошибка компиляции: недопустимая escape-последовательность |
