# JAVA_06_08. Шифр Цезаря — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `3` + `Hello, World!` | `Khoor, Zruog!\n` | Буквы сдвинуты, знаки сохранены |
| `1` + `abc xyz` | `bcd yza\n` | `z` заворачивается в `a` |
| `0` + `Java` | `Java\n` | Сдвиг 0 ничего не меняет |
| `26` + `abc` | `abc\n` | Полный оборот (если нормализовать k) |
| `3` + `Zz` | `Cc\n` | Заворот в обоих регистрах |

> В условии `k <= 25`; тест с `k = 26` проверяет дополнительную нормализацию `k % 26` — она не обязательна, но полезна.

## Крайние случаи

- **Заворот алфавита** — `x`, `y`, `z` переходят в начало.
- **Оба регистра** — разные базы `'a'` и `'A'`.
- **Знаки и цифры** — не шифруются.
- **k = 0** — текст не меняется.
