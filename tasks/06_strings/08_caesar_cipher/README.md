Шифр Цезаря сдвигает каждую букву алфавита на `k` позиций вперёд. Например, при `k = 3`: `a → d`, `x → a`, `A → D`.

Входные данные:

1. первая строка — целое `k` (`0 <= k <= 25`);
2. вторая строка — текст.

Зашифруй текст и выведи результат с переносом строки:

- строчные латинские буквы сдвигаются в пределах `a..z`;
- заглавные — в пределах `A..Z`;
- цифры, пробелы и знаки препинания остаются без изменений;
- сдвиг «заворачивается»: после `z` идёт `a`.

```java
if (c >= 'a' && c <= 'z') {
    sb.append((char) ('a' + (c - 'a' + k) % 26));
} else if (c >= 'A' && c <= 'Z') {
    sb.append((char) ('A' + (c - 'A' + k) % 26));
} else {
    sb.append(c);
}
```

Важная деталь ввода: после `sc.nextInt()` в буфере остаётся перевод строки, поэтому перед `sc.nextLine()` нужен промежуточный `sc.nextLine()`.

| 1<br>abc xyz | bcd yza |
