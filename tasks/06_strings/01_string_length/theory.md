# Разбор задания

## String — объект, а не массив

В C строка — это `char *`. В Java `String` — полноценный объект:

```java
String s = "Hello";
int len = s.length();   // 5
char c = s.charAt(0);   // 'H'
```

Строки в Java **неизменяемы**: любой метод, «меняющий» строку, возвращает новую.

## nextLine() и next()

| Метод | Что читает |
| --- | --- |
| `next()` | одно слово до пробела |
| `nextLine()` | всё до конца строки, включая пробелы |

Если нужно посчитать длину фразы `Hello, World!`, подходит только `nextLine()`: `next()` вернёт `Hello,` — 6 символов.

## length() против длины массива

| Что | Как узнать размер |
| --- | --- |
| Массив `int[] a` | `a.length` — поле, без скобок |
| Строка `String s` | `s.length()` — метод, со скобками |

Это частая причина ошибок компиляции.

## Пустая строка

`"".length()` равно `0`. Если входная строка пустая, `nextLine()` вернёт `""`, а не `null` — программа корректно напечатает `0`.

`null` — отдельное значение («ссылка ни на что»). Вызов `null.length()` приведёт к `NullPointerException`; `nextLine()` при наличии строки в вводе `null` не возвращает.

## Длина и Unicode

`length()` считает **UTF-16 code units**, а не видимые символы. Для ASCII и кириллицы длина совпадает с количеством символов. Для эмодзи и редких иероглифов может отличаться — подробности выходят за рамки задания.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `line.length` без скобок | Ошибка компиляции |
| `sc.next()` | Считано только первое слово |
| `line.size()` | У `String` нет метода `size()` (он есть у коллекций) |
| `strlen(line)` | Такого метода в Java нет |
