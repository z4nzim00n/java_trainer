## JAVA_06_01. Длина строки

### Задание
| Java_06_01 ||
| ------ | ------- |
| **Темы:** | Класс `String`, `Scanner.nextLine()`, метод `length()`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает **одну строку целиком** (вместе с пробелами) и выводит количество символов в ней с переносом строки в конце.

Для чтения строки целиком используй `nextLine()`, а не `next()`: `next()` вернул бы только первое слово.

```java
Scanner sc = new Scanner(System.in);
String line = sc.nextLine();
System.out.println(line.length());
```

Обрати внимание: в Java `length()` — это **метод** (со скобками), а не поле, как `strlen` в C.

Гарантируется, что в строке нет символов табуляции и переносов — только одна строка.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Hello | 5 |
| Hello, World! | 13 |
| (пустая строка) | 0 |
