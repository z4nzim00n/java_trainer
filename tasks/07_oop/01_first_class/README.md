## JAVA_07_01. Первый класс

### Задание
| Java_07_01 ||
| ------ | ------- |
| **Темы:** | Классы и объекты, поля, методы, `new`, доступ через точку. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Опиши в файле `Main.java` класс `Rectangle` — **package-private** (без слова `public`), в том же файле, что и класс `Main`:

- поля `double width` и `double height`;
- метод `double area()` — возвращает площадь (`width * height`);
- метод `double perimeter()` — возвращает периметр (`2 * (width + height)`).

В методе `main` считай два вещественных числа — ширину и высоту, создай объект `Rectangle`, заполни его поля и выведи площадь и периметр на двух строках в формате `%.2f` (ровно два знака после точки).

Для вещественных чисел обязательно: `sc.useLocale(Locale.US)` при чтении и `System.out.printf(Locale.US, "%.2f\n", ...)` при выводе. В конце каждой строки — перенос `\n`.

Гарантируется, что ввод корректен: два положительных числа, разделённых пробелом.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3 4 | 12.00<br>14.00 |
| 2.5 2 | 5.00<br>9.00 |
| 1 1 | 1.00<br>4.00 |
