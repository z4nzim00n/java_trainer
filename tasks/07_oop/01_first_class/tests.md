# JAVA_07_01. Первый класс — Тесты

## Компиляция

Для проверки собственного решения:

```bash
javac -encoding UTF-8 Main.java
java Main
```

Для проверки эталона:

```bash
javac -encoding UTF-8 Solution.java
java Solution
```

Для проверки комментированной версии:

```bash
javac -encoding UTF-8 SolutionCommented.java
java SolutionCommented
```

> Это отдельные программы. Собирайте только один файл за раз.

## Проверка вывода

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `3 4` | `12.00\n14.00\n` | `echo "3 4" \| java Main` | Площадь 3·4=12, периметр 2·(3+4)=14 |
| `2.5 2` | `5.00\n9.00\n` | `echo "2.5 2" \| java Main` | Дробная ширина: проверяем Locale.US при чтении |
| `1 1` | `1.00\n4.00\n` | `echo "1 1" \| java Main` | Единичный квадрат |

## Крайние случаи

- **Дробный ввод** (`2.5 2`): без `sc.useLocale(Locale.US)` на русской Windows `nextDouble()` упадёт с `InputMismatchException` — Scanner ждёт запятую.
- **Целый ввод** (`3 4`): `%.2f` обязан дописать `.00` — просто `println(12.0)` напечатает `12.0`, это не пройдёт.
- **Округление**: `%.2f` округляет, а не отбрасывает: `2.675` может дать `2.67` из-за двоичного представления double — в тестах таких значений нет.
- **Пустой ввод**: по условию ввод всегда корректен (два положительных числа), поэтому EOF-случаи не проверяются.
