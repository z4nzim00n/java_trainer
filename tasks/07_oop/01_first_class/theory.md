# Разбор задания

## Класс — это тип, объект — значение этого типа

В C ты описывал данные через `struct`, а функции писал отдельно. В Java данные и функции, которые с ними работают, объединяются в **класс**:

```java
class Rectangle {
    double width;      // поле (состояние)
    double height;     // поле

    double area() {    // метод (поведение)
        return width * height;
    }
}
```

| Понятие | Аналогия с C | Что это |
| --- | --- | --- |
| Класс | Определение `struct` + функции рядом | Описание: какие есть поля и методы |
| Объект | Конкретная переменная типа `struct` | Экземпляр класса, созданный через `new` |
| Поле | Поле структуры | Переменная, принадлежащая объекту |
| Метод | Функция, первым аргументом получающая `struct*` | Функция, принадлежащая классу |

## Создание объекта и доступ через точку

```java
Rectangle rect = new Rectangle();  // создали объект, rect — ссылка на него
rect.width = 3;                    // записали значение в поле
rect.height = 4;
double s = rect.area();            // вызвали метод: s == 12.0
```

- `new Rectangle()` выделяет память под объект и возвращает **ссылку** (аналог указателя, но без арифметики и без `free` — память освобождает сборщик мусора).
- Доступ к полям и методам — через точку: `rect.width`, `rect.area()`.
- Поля получают значения по умолчанию: `0.0` для `double`, `0` для `int`, `null` для ссылочных типов. Локальные переменные в методах, в отличие от полей, обязаны быть инициализированы вручную.

## Метод видит поля своего объекта

Когда ты пишешь `rect.area()`, внутри метода `area` имена `width` и `height` означают поля именно объекта `rect`. Если создать второй объект `rect2`, у него будут **свои** `width` и `height`, и `rect2.area()` посчитает площадь по ним. Никаких глобальных переменных не нужно.

## Один файл — один публичный класс

Публичный класс обязан называться так же, как файл (`Main.java` → `public class Main`). Все остальные классы в этом же файле объявляются **без `public`** (package-private):

```java
public class Main { ... }

class Rectangle { ... }   // без public — так правильно
```

Если написать `public class Rectangle` в файле `Main.java`, компилятор выдаст ошибку: *class Rectangle is public, should be declared in a file named Rectangle.java*.

## Locale.US для дробных чисел

На русской Windows `Scanner.nextDouble()` и `printf("%f")` используют запятую как десятичный разделитель. Тесты подают числа с точкой (`2.5`), поэтому:

```java
Scanner sc = new Scanner(System.in);
sc.useLocale(Locale.US);                          // читать 2.5, а не 2,5
System.out.printf(Locale.US, "%.2f\n", value);    // печатать 5.00, а не 5,00
```

`%.2f` — ровно два знака после точки с округлением: `12` → `12.00`, `12.567` → `12.57`.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `Rectangle rect;` без `new` | Переменная-ссылка есть, объекта нет: `rect.width` → `NullPointerException` |
| `public class Rectangle` в `Main.java` | Ошибка компиляции: имя публичного класса не совпадает с именем файла |
| `rect.area;` без скобок | Обращение к методу без вызова — ошибка компиляции |
| `printf("%.2f", x)` без `Locale.US` | На русской Windows вывод с запятой — тест не проходит |
| Забыл `\n` в формате | Обе строки склеиваются, вывод не совпадает с эталоном |
| `double area() { width * height; }` | Ошибка компиляции: missing return statement — нужен `return` |
