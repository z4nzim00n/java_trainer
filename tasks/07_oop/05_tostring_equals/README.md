## JAVA_07_05. toString и equals

### Задание
| Java_07_05 ||
| ------ | ------- |
| **Темы:** | Переопределение методов `Object`, `toString()`, `equals()`, `instanceof`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Опиши **package-private** класс `Book` с полями `String title` и `int year` и конструктором `Book(String title, int year)`.

Переопредели два метода класса `Object`:

- `toString()` — возвращает строку вида `Название (год)`, например `Java (2024)`;
- `equals(Object other)` — возвращает `true`, если у сравниваемого объекта совпадают и название, и год.

В `main` считай данные двух книг (название — одно слово, затем год, и так дважды), создай объекты и выведи:

```text
<первая книга через toString>
equal / not equal
```

Сравнение `equals` должно корректно работать и при сравнении с `null`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Java 2024 Java 2024 | Java (2024)<br>equal |
| Java 2024 Go 2019 | Java (2024)<br>not equal |
| Java 2024 Java 2020 | Java (2024)<br>not equal |
