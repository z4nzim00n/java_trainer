# Разбор задания

## Абстрактный класс

```java
abstract class Shape {
    abstract double area();
}
```

- `abstract`-класс нельзя создать через `new`.
- `abstract`-метод объявлен без тела: наследники обязаны его реализовать.
- Если наследник не реализует абстрактный метод, он тоже должен быть `abstract`.

## extends и @Override

```java
class Circle extends Shape {
    private double radius;

    Circle(double radius) {
        this.radius = radius;
    }

    @Override
    double area() {
        return Math.PI * radius * radius;
    }
}
```

`Circle` получает всё, что есть в `Shape`, и добавляет своё. `@Override` проверяет, что метод действительно переопределяет метод предка.

## Полиморфизм

```java
Shape shape = new Circle(2);
shape.area();   // вызовется Circle.area()
```

Переменная типа `Shape` может хранить любой объект-наследник. Какой именно метод вызвать, JVM решает по **реальному типу объекта** (динамическая диспетчеризация), а не по типу переменной.

Это позволяет писать код, не зависящий от конкретной фигуры:

```java
double total = 0;
for (Shape s : shapes) {
    total += s.area();
}
```

## super

`super` обращается к предку. Чаще всего — к его конструктору:

```java
class NamedShape extends Shape {
    NamedShape() {
        super();   // вызов конструктора предка (здесь неявный)
    }
}
```

В нашей иерархии у `Shape` нет полей, поэтому явный `super()` не нужен: компилятор вставит вызов конструктора без аргументов сам.

## Почему не интерфейс

`Shape` мог бы быть интерфейсом: у него нет состояния и общей реализации. Для одной абстрактной операции это тоже правильный выбор. Абстрактный класс удобен, когда есть общие поля или готовая логика. В разделе про коллекции встретятся оба механизма.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `new Shape()` | Ошибка: абстрактный класс нельзя инстанцировать |
| Забыть реализовать `area()` | Ошибка компиляции в неабстрактном классе |
| `@Override` с неверной сигнатурой | Ошибка компиляции — это и есть польза аннотации |
| Нет `useLocale(Locale.US)` | На русской Windows площадь печатается с запятой |
| `Shape shape = new Shape()` | Нельзя, даже если добавить тело `area` в абстрактный класс |
