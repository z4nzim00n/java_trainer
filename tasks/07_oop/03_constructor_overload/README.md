## JAVA_07_03. Перегрузка конструкторов

### Задание
| Java_07_03 ||
| ------ | ------- |
| **Темы:** | Конструкторы, перегрузка, `this(...)`, значения полей по умолчанию. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Опиши в файле `Main.java` **package-private** класс `Point` (без слова `public`) с полями `int x` и `int y` и двумя конструкторами:

- `Point(int x, int y)` — сохраняет переданные координаты;
- `Point()` — создаёт точку в начале координат `(0, 0)`; реализуй его через вызов основного конструктора: `this(0, 0);`.

Добавь метод `String coords()`, возвращающий координаты через пробел: `x + " " + y`.

В `main` считай два целых числа, создай две точки — с координатами из ввода и без аргументов — и выведи результат `coords()` каждой на отдельной строке.

```java
Point p1 = new Point(x, y);
Point p2 = new Point();
System.out.println(p1.coords());
System.out.println(p2.coords());
```

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3 5 | 3 5<br>0 0 |
| -1 2 | -1 2<br>0 0 |
| 0 0 | 0 0<br>0 0 |
