# JAVA_07_03. Перегрузка конструкторов — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

> В каждом файле свой класс `Point`, поэтому собирайте файлы по одному.

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `3 5` | `3 5\n0 0\n` | Первая точка из ввода, вторая — по умолчанию |
| `-1 2` | `-1 2\n0 0\n` | Отрицательная координата |
| `0 0` | `0 0\n0 0\n` | Обе точки совпали |
| `100 -100` | `100 -100\n0 0\n` | Большие значения |

## Крайние случаи

- **Нулевые координаты** — конструктор по умолчанию даёт то же самое.
- **Отрицательные значения** — `int` знаковый, ограничений нет.
- **Порядок конструкторов** — сначала с аргументами, затем без.
