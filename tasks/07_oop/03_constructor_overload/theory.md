# Разбор задания

## Конструктор

Конструктор — метод, который вызывается при `new` и инициализирует объект. Отличия:

- имя совпадает с именем класса;
- нет возвращаемого типа (даже `void`);
- вызывается только через `new`.

```java
Point p = new Point(3, 5);
```

## Перегрузка

В одном классе может быть несколько конструкторов с **разными сигнатурами** (типами и количеством параметров):

```java
Point(int x, int y) { ... }
Point()             { ... }
```

Компилятор выбирает подходящий по аргументам вызова. Это и есть перегрузка.

## this(...)

Один конструктор может делегировать другому:

```java
Point() {
    this(0, 0);
}
```

Правила:

- вызов `this(...)` должен стоять **первой** строкой конструктора;
- нельзя вызвать `this(...)` из обычного метода.

## Поля по умолчанию

Поля примитивных типов инициализируются нулями ещё до конструктора. Поэтому в `Point()` даже без присваивания `x` и `y` были бы `0`. Но явный `this(0, 0)` показывает намерение и не дублирует логику.

## Имя параметра и поле

```java
Point(int x, int y) {
    this.x = x;
    this.y = y;
}
```

`this.x` — поле объекта, `x` — параметр. Без `this` присваивание `x = x` ничего не делает.

## Что если объявить свои конструкторы

Если в классе есть хотя бы один конструктор, компилятор **не** добавляет конструктор по умолчанию. Именно поэтому в этом задании `Point()` приходится писать явно.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `void Point() { }` | Это метод, а не конструктор; `new Point()` его не вызовет |
| `this(0, 0)` не первой строкой | Ошибка компиляции |
| `x = x` без `this` | Поле не меняется |
| Два конструктора с одинаковой сигнатурой | Ошибка компиляции |
| Рассчитывать на неявный `Point()` | Его нет, если объявлены другие конструкторы |
