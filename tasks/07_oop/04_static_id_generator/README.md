## JAVA_07_04. Статический счётчик ID

### Задание
| Java_07_04 ||
| ------ | ------- |
| **Темы:** | `static`-поля, отличие от полей экземпляра, инкремент, конструктор. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Опиши **package-private** класс `User`:

- `private static int nextId = 1;` — общий счётчик для всех пользователей;
- `private int id;` и `private String name;` — поля конкретного объекта;
- конструктор `User(String name)`: сохраняет имя и выдаёт `id = nextId++;`
- методы `getId()` и `getName()`.

В `main` считай число `N`, затем `N` имён (каждое — одно слово), создай пользователей в порядке ввода и выведи для каждого строку:

```text
<id> <name>
```

Все пользователи получают последовательные номера `1, 2, 3, ...` — счётчик статический, он один на весь класс.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2<br>Alice Bob | 1 Alice<br>2 Bob |
| 1<br>Solo | 1 Solo |
| 3<br>A B C | 1 A<br>2 B<br>3 C |
