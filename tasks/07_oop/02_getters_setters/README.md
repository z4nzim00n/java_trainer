## JAVA_07_02. Геттеры и сеттеры

### Задание
| Java_07_02 ||
| ------ | ------- |
| **Темы:** | Инкапсуляция, `private`, геттеры, сеттеры, валидация. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Опиши в файле `Main.java` package-private класс `User` (без `public`, в том же файле):

- **приватные** поля `private String name` и `private int balance`;
- конструктор `User(String name, int balance)`, сохраняющий параметры в поля;
- геттер `String getName()` — возвращает имя;
- геттер `int getBalance()` — возвращает баланс;
- сеттер `void setBalance(int balance)` — присваивает новый баланс, **только если он неотрицательный**; отрицательный баланс сеттер молча игнорирует (поле не меняется).

Программа считывает:

1. первую строку: имя (одно слово) и начальный баланс (целое число);
2. вторую строку: новый баланс (целое число).

Вывод:

1. сначала строка `<name>: <balance>` с текущим балансом;
2. затем, если новый баланс `>= 0`: примени его через сеттер и выведи `<name>: <newBalance>`; иначе выведи `Invalid balance`.

Каждая строка вывода заканчивается переносом `\n`. Гарантируется, что имя — одно слово без пробелов, начальный баланс неотрицателен.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Alice 100<br>50 | Alice: 100<br>Alice: 50 |
| Bob 30<br>-5 | Bob: 30<br>Invalid balance |
