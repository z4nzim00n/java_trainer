# JAVA_07_02. Геттеры и сеттеры — Тесты

## Компиляция

Для проверки собственного решения:

```bash
javac -encoding UTF-8 Main.java
java Main
```

Для проверки эталона:

```bash
javac -encoding UTF-8 Solution.java
java Solution
```

Для проверки комментированной версии:

```bash
javac -encoding UTF-8 SolutionCommented.java
java SolutionCommented
```

> Это отдельные программы. Собирайте только один файл за раз.

## Проверка вывода

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `Alice 100\n50` | `Alice: 100\nAlice: 50\n` | `printf 'Alice 100\n50\n' \| java Main` | Новый баланс неотрицателен — сеттер применил его |
| `Bob 30\n-5` | `Bob: 30\nInvalid balance\n` | `printf 'Bob 30\n-5\n' \| java Main` | Отрицательный баланс отклонён, поле не изменилось |

## Крайние случаи

- **Нулевой баланс** (`newBalance = 0`): условие `>= 0` включает ноль — сеттер обязан его принять.
- **Отрицательный баланс**: сеттер молча игнорирует значение; программа печатает `Invalid balance`, а не новое значение. Если напечатать старое значение поля вместо сообщения — тест не пройдёт.
- **Имя с пробелом**: по условию имя — одно слово, `sc.next()` читает ровно один токен.
- **Пустой ввод**: по условию ввод корректен, EOF-случаи не проверяются.
