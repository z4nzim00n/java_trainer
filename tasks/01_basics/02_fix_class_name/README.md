## JAVA_01_02. Исправь имя класса и метод main

### Задание
| Java_01_02 ||
| ------ | ------- |
| **Темы:** | Имя класса и имя файла, чувствительность к регистру, `static`, точка входа. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

В файле `Main.java` уже написана программа: она считывает два целых числа и выводит их произведение с переносом строки в конце. Но в коде допущены две ошибки, из-за которых программа не работает:

1. Класс объявлен как `public class main` — с маленькой буквы. Имя публичного класса обязано совпадать с именем файла: файл `Main.java` — класс `Main`.
2. Метод объявлен как `public void main(String[] args)` — пропущено слово `static`. JVM ищет точку входа только среди статических методов.

Исправь обе ошибки, чтобы программа компилировалась и запускалась. Логику программы менять не нужно: как и было задумано, она считывает два целых числа (через пробел или с новой строки) и выводит их произведение. В конце вывода — один перенос строки (`println`).

Пока ошибки не исправлены, `Main.java` намеренно не компилируется — это нормально.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2 2 | 4 |
| -4 4 | -16 |
| 0 5 | 0 |
