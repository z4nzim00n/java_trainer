# Разбор задания

## Ошибка 1: имя класса не совпадает с именем файла

В Java имя **публичного** класса обязано буква в букву совпадать с именем файла:

| Файл | Правильное объявление | Неправильно |
| --- | --- | --- |
| `Main.java` | `public class Main` | `public class main`, `public class MAIN` |
| `Solution.java` | `public class Solution` | `public class solution` |

Java чувствительна к регистру: `main`, `Main` и `MAIN` — три разных идентификатора. Компилятор сразу сообщает:

```text
error: class main is public, should be declared in a file named main.java
```

То есть компилятор как бы говорит: «Раз класс называется `main`, переименуй файл в `main.java`». Но по условию файл обязан называться `Main.java`, поэтому исправляем именно имя класса: `public class Main`.

> В Си имя файла вообще ни на что не влияет — можно было назвать файл как угодно. В Java имя файла — часть контракта с компилятором.

## Ошибка 2: у метода main пропущен static

Точка входа в Java-программу имеет строго фиксированную сигнатуру:

```java
public static void main(String[] args)
```

Что будет, если убрать `static`:

| Что написано | Компиляция | Запуск |
| --- | --- | --- |
| `public static void main(String[] args)` | OK | OK |
| `public void main(String[] args)` | OK | Ошибка: `Main method not found in class Main` |

Коварство в том, что код **компилируется** — метод без `static` синтаксически корректен. Но JVM при запуске не создаёт объект класса `Main`, а вызывает метод «напрямую у класса». Нестатический метод для этого не подходит: ему нужен объект. Поэтому JVM не находит точку входа и падает.

> Аналогия с Си: `static`-метод в Java похож на обычную функцию, не привязанную к объекту. JVM ищет именно такую «функцию» с именем `main`.

## Как читать ошибки компилятора

Сообщение javac содержит имя файла, номер строки и текст ошибки:

```text
Main.java:5: error: class main is public, should be declared in a file named main.java
```

Смотри номер строки и исправляй то, на что он указывает. После исправления первой ошибки компилятор может показать следующую — это нормально, исправляй по одной.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `public class main` | Не компилируется: имя класса не совпадает с именем файла |
| `public void main(...)` без `static` | Компилируется, но при запуске `Main method not found` |
| `public static void Main(String[] args)` | Компилируется, но JVM не находит `main` (регистр!) |
| Переименовал файл вместо класса | Файл обязан называться `Main.java` по условию |
| Исправил только одну ошибку | Программа всё ещё не работает — нужны обе правки |
