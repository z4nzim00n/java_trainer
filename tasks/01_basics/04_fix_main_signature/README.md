## JAVA_01_04. Неправильная сигнатура main

### Задание
| Java_01_04 ||
| ------ | ------- |
| **Темы:** | Сигнатура `main`, точка входа, `static`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Метод `main` назван с большой буквы и объявлен без параметра `String[] args`, поэтому JVM не считает его точкой входа. Исправь сигнатуру: метод должен называться `main` и принимать массив строк.

Логику не меняй: программа считывает одно целое число и выводит его удвоенное значение с переносом строки.

Пока ошибка не исправлена, программа либо не компилируется, либо падает с `Main method not found`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 4 | 8 |
| -3 | -6 |

### Как проверить

```bash
bash run_tests1_4.sh
```
