# JAVA_01_01. Первая программа — Тесты

## Компиляция

Для проверки собственного решения:

```bash
javac -encoding UTF-8 Main.java
java Main
```

Для проверки эталона:

```bash
javac -encoding UTF-8 Solution.java
java Solution
```

Для проверки комментированной версии:

```bash
javac -encoding UTF-8 SolutionCommented.java
java SolutionCommented
```

> Это отдельные программы. Собирайте только один файл за раз.

## Проверка вывода

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| (пусто) | `Hello, Java!\n` | `java Main < /dev/null` | Единственный случай: ввода нет |

## Как увидеть перенос строки

При обычном запуске перенос строки в конце не виден. Посмотреть точные байты результата:

```bash
java Main < /dev/null | od -An -t x1
```

Ожидаемые байты:

```text
48 65 6c 6c 6f 2c 20 4a 61 76 61 21 0a
```

Последний байт `0a` — это `\n`, перенос строки. Если его нет — вы использовали `print` вместо `println`.

> На Windows `println` печатает `\r\n` (байты `0d 0a`) — это особенность платформы. Автотесты нормализуют переносы (`\r\n` → `\n`), поэтому на любой ОС достаточно одного `println`.

Проверка количества байтов:

```bash
java Main < /dev/null | wc -c
```

Ожидаемое количество: `13` (12 символов строки + 1 перенос).
