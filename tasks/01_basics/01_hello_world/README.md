## JAVA_01_01. Первая программа

### Задание
| Java_01_01 ||
| ------ | ------- |
| **Темы:** | Структура программы, класс, метод `main`, `System.out.println`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Не используются |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши свою первую программу на Java. Программа должна вывести на экран строку:

```text
Hello, Java!
```

В конце вывода должен быть один перенос строки (используй `System.out.println`, а не `System.out.print`).

Программа ничего не считывает из стандартного ввода.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| (пусто) | Hello, Java! |
