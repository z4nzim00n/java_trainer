# Разбор задания

## Примитивные типы Java

В Java 8 примитивных типов:

| Тип | Что хранит | Пример литерала |
| --- | --- | --- |
| `byte`, `short`, `int`, `long` | Целые числа | `42`, `42L` |
| `float`, `double` | Вещественные числа | `3.14f`, `3.14` |
| `char` | Один символ Unicode | `'A'`, `'\n'` |
| `boolean` | Логическое значение | `true`, `false` |

`String` — **не** примитив, это класс. Но используется так же часто.

## Ошибка 1: `int b = sc.nextDouble();`

`nextDouble()` возвращает `double`. Java не разрешает неявно сужать тип: `double` → `int` потерял бы дробную часть. Компилятор требует явного приведения:

```java
int b = (int) sc.nextDouble();   // компилируется, но дробная часть потеряется
double b = sc.nextDouble();      // правильно, если нужна точность
```

В задаче нужна точность — используем `double`.

## Ошибка 2: `boolean flag = 1;`

В Java нет неявного преобразования числа в `boolean` (в отличие от C, где `0` — это ложь, а всё остальное — истина). Разрешено только:

```java
boolean flag = true;
boolean flag = false;
boolean flag = n > 0;   // результат сравнения
```

## Ошибка 3: `String s = 'x';`

| Запись | Тип | Что это |
| --- | --- | --- |
| `'x'` | `char` | Один символ |
| `"x"` | `String` | Строка из одного символа |

Присвоить `char` в `String` нельзя — компилятор скажет `incompatible types`.

## Почему `println(a + b)` даёт `5.5`

Если один операнд `double`, второй (`int`) автоматически расширяется до `double`. Результат — `double`, который `println` печатает с точкой.

## Locale

`sc.useLocale(Locale.US)` нужен, чтобы `nextDouble()` принимал `3.5`, а не требовал `3,5`. На русской системе разделитель по умолчанию — запятая.

## Сравнение с C

| C | Java |
| --- | --- |
| `int flag = 1; if (flag)` | `boolean flag = true;` — числа и boolean не смешиваются |
| `char s[] = "x"` | `String s = "x"` |
| `double b; scanf("%lf", &b)` | `double b = sc.nextDouble();` |
