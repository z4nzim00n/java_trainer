## JAVA_01_05. Исправление типов

### Задание
| Java_01_05 ||
| ------ | ------- |
| **Темы:** | Примитивные типы, `double` и `int`, `boolean`, `char` и `String`, литералы. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

В программе три ошибки типов. Исправь объявления, не меняя логику: программа считывает целое число `a` и вещественное число `b`, затем выводит их сумму с переносом строки.

Подсказки:

1. `nextDouble()` возвращает `double`, а не `int`.
2. `boolean` принимает только `true` или `false`, но не `1`.
3. Строковый литерал пишется в двойных кавычках, символьный — в одинарных.

Пока ошибки не исправлены, `Main.java` намеренно не компилируется.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2 3.5 | 5.5 |
| 0 0.0 | 0.0 |
| -1 2.5 | 1.5 |
