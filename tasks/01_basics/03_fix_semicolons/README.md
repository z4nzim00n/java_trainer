## JAVA_01_03. Пропущенные точки с запятой

### Задание
| Java_01_03 ||
| ------ | ------- |
| **Темы:** | Точка с запятой, инструкции, ошибки компиляции. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

В программе пропущены точки с запятой. Каждая инструкция в Java заканчивается символом `;`. Исправь код так, чтобы программа компилировалась и работала: она считывает одно целое число и выводит его квадрат с переносом строки.

Пока ошибки не исправлены, `Main.java` намеренно не компилируется.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3 | 9 |
| -5 | 25 |
| 0 | 0 |

bash run_tests1_3.sh
