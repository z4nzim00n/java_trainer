# Разбор задания

## Точка с запятой

В Java каждая **инструкция** (statement) заканчивается `;`. Это не украшение: компилятор воспринимает `;` как конец инструкции. Если её нет, он продолжает читать следующую строку как продолжение текущей и почти всегда выдаёт ошибку.

```java
int n = sc.nextInt()      // ошибка: ';' expected
int square = n * n;       // компилятор рассматривает как продолжение
```

Типичное сообщение компилятора:

```text
Main.java:5: error: ';' expected
        Scanner sc = new Scanner(System.in)
                                           ^
```

Стрелка `^` указывает, где компилятор ждал `;`.

## Где `;` НЕ нужна

- После объявления класса или метода (после `}`).
- После `if`, `for`, `while` — заголовок не заканчивается `;`, иначе тело станет пустой инструкцией.
- Внутри `for (...)` между секциями стоят `;`, но это часть заголовка.

```java
if (n > 0) {          // без ;
    System.out.println(n);   // с ;
}
```

## Как искать ошибку

Компилятор сообщает **первую** ошибку и иногда путается в следующих строках. Исправляй по одной сверху вниз:

```bash
javac -encoding UTF-8 Main.java
```

| Ошибка | Значение |
| --- | --- |
| `';' expected` | Пропущена точка с запятой |
| `';' expected` на строке ниже настоящей | Скорее всего, забыли `;` в предыдущей инструкции |

## Частая ошибка новичка

Писать `;` после `if`, `for`, `while`:

```java
for (int i = 0; i < 3; i++);   // пустой цикл!
{
    System.out.println("x");   // выполнится один раз
}
```

Это компилируется, но работает не так, как кажется. Логических ошибок компилятор не ловит.
