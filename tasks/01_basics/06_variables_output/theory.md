# Разбор задания

## Переменная — это имя и тип

В Java у каждой переменной тип фиксирован навсегда:

```java
int i = 42;        // тип int, значение 42
double d = 3.14;   // тип double
boolean b = true;  // тип boolean
char c = 'A';      // тип char, ровно один символ
String s = "Hello";// тип String, строка
```

`Java` — строго типизированный язык: в `int` нельзя положить строку, а в `boolean` — число.

## Литералы: кавычки решают

| Литерал | Тип | Пример |
| --- | --- | --- |
| `'A'` | `char` | Одинарные кавычки, один символ |
| `"A"` | `String` | Двойные кавычки, строка |
| `42` | `int` | Целое без точки |
| `3.14` | `double` | Вещественное с точкой |
| `true` | `boolean` | Ключевое слово |

Ошибка `String s = 'x';` возникает именно из-за путаницы `char` и `String`.

## Конкатенация строк

Оператор `+` работает по-разному в зависимости от типов:

```java
System.out.println(2 + 3);          // 5 — арифметика
System.out.println("int: " + 42);   // int: 42 — конкатенация
System.out.println("a" + 1 + 2);    // a12 — слева направо
System.out.println(1 + 2 + "a");    // 3a — сначала сложение
```

Если хотя бы один операнд — строка, результат становится строкой. В задании мы приклеиваем значение к строке-подписи.

## println и перевод строки

`System.out.println(x)` печатает `x` и **добавляет** перевод строки. Поэтому пять `println` дают ровно пять строк, и последняя заканчивается `\n` — как требуют тесты.

`System.out.print(x)` печатает без перевода строки.

## Именование

По конвенции Java имена переменных пишутся в `camelCase` со строчной буквы: `maxValue`, `userBalance`. Имена классов — `PascalCase`: `Main`, `UserService`. Это не требование компилятора, но его проверяют на ревью в Школе 21.

## Частые ошибки

| Ошибка | Сообщение компилятора |
| --- | --- |
| `int i = 3.14;` | `possible lossy conversion from double to int` |
| `boolean b = 1;` | `int cannot be converted to boolean` |
| `char c = "A";` | `String cannot be converted to char` |
| `String s = Hello;` | `cannot find symbol: class Hello` |
