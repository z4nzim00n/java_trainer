## JAVA_01_06. Переменные и типы

### Задание
| Java_01_06 ||
| ------ | ------- |
| **Темы:** | Объявление переменных, литералы, `int`, `double`, `boolean`, `char`, `String`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Не используются |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Объяви пять переменных разных типов и выведи их через `System.out.println` строго в таком виде:

```text
int: 42
double: 3.14
boolean: true
char: A
String: Hello
```

Значения: целое `42`, вещественное `3.14`, логическое `true`, символ `'A'`, строка `"Hello"`. В конце каждой строки — перенос строки.

Программа ничего не считывает.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| (пусто) | int: 42<br>double: 3.14<br>boolean: true<br>char: A<br>String: Hello |
