## JAVA_12_06. Матрица: сумма и максимум

### Задание

Считай размеры матрицы `rows` и `cols`, затем `rows * cols` целых чисел (построчно). Выведи сумму всех элементов и максимум:

```text
Sum: <сумма>
Max: <максимум>
```

```java
int[][] matrix = new int[rows][cols];
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        matrix[i][j] = sc.nextInt();
    }
}
```

Гарантируется, что `rows >= 1` и `cols >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2 3<br>1 2 3 4 5 6 | Sum: 21<br>Max: 6 |
| 1 1<br>-5 | Sum: -5<br>Max: -5 |
| 2 2<br>0 0 0 0 | Sum: 0<br>Max: 0 |
