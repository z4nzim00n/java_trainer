# Разбор задания

## Двумерный массив

```java
int[][] matrix = new int[rows][cols];
matrix[0][1] = 5;
```

`matrix` — массив массивов: `matrix[i]` — строка `i`, `matrix[i][j]` — элемент в строке `i`, столбце `j`.

## Вложенные циклы

```java
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        ...
    }
}
```

Внешний цикл идёт по строкам, внутренний — по столбцам. Такой порядок совпадает с порядком ввода и с расположением элементов в памяти.

## Сумма и максимум

```java
long sum = 0;
int max = matrix[0][0];
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        sum += matrix[i][j];
        if (matrix[i][j] > max) {
            max = matrix[i][j];
        }
    }
}
```

Максимум инициализирован первым элементом, а не нулём: матрица может состоять из отрицательных чисел. Сумма — `long` на случай больших значений.

## Строки разной длины

В Java «зубчатый» массив допустим:

```java
int[][] jagged = new int[3][];
jagged[0] = new int[2];
```

Но в этой задаче матрица прямоугольная, поэтому циклы используют общие `rows` и `cols`.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `max = 0` | Неверно для отрицательной матрицы |
| `matrix[cols][rows]` | Перепутаны размеры |
| `j < rows` во внутреннем цикле | Выход за границу, если `cols < rows` |
| `sum` как `int` | Возможно переполнение |
| Чтение всех чисел в один массив | Потеря структуры строк |
