# Разбор задания

## Именованные константы

Вместо «магических чисел» лучше объявлять константы:

```java
static final int CUPS_PER_PERSON = 2;
static final int WATER_PER_CUP_ML = 200;
static final int COFFEE_PER_CUP_G = 20;
```

`static final` — константа класса: значение задаётся один раз и не меняется. Имя принято писать заглавными буквами.

## Вычисления

```java
int cups = people * CUPS_PER_PERSON;
int water = cups * WATER_PER_CUP_ML;
int coffee = cups * COFFEE_PER_CUP_G;
```

Сначала считаем общее число чашек, затем расход ресурсов. Такая последовательность отражает логику задачи.

## Переполнение

`int` вмещает около 2.1 миллиарда. При `people ≈ 10^6` воды будет `4 * 10^8` мл — ещё помещается. В реальной программе для количеств лучше брать `long`, но по условию хватает `int`.

## Вывод

```java
System.out.println("Cups: " + cups);
System.out.println("Water: " + water + " ml");
System.out.println("Coffee: " + coffee + " g");
```

Конкатенация автоматически превращает числа в строки. Единицы измерения — часть ожидаемого вывода, их нельзя пропускать.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| Забыть удвоение чашек | Вода и кофе в два раза меньше |
| Перепутать граммы и миллилитры | Неверные единицы в выводе |
| Лишний пробел в строке | Побайтовое сравнение не пройдёт |
| `print` вместо `println` | Строки склеятся в одну |
| `double` для целых количеств | Появятся `.0` в выводе |
