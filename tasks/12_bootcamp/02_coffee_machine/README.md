## JAVA_12_02. Кофемашина

### Задание
| Java_12_02 ||
| ------ | ------- |
| **Темы:** | Арифметика, константы, форматированный вывод. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Задача в духе дня про классы и массивы в Java Bootcamp Школы 21.

В офис пришло `P` человек. Каждый выпивает по **2 чашки** кофе. На одну чашку нужно:

- `200` мл воды;
- `20` г кофе.

Считай `P` и выведи три строки:

```text
Cups: <чашек>
Water: <воды> ml
Coffee: <кофе> g
```

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 1 | Cups: 2<br>Water: 400 ml<br>Coffee: 40 g |
| 3 | Cups: 6<br>Water: 1200 ml<br>Coffee: 120 g |
| 0 | Cups: 0<br>Water: 0 ml<br>Coffee: 0 g |

bash run_tests12_2.sh
