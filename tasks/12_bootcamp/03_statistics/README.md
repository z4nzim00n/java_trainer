## JAVA_12_03. Статистика

### Задание
| Java_12_03 ||
| ------ | ------- |
| **Темы:** | Массивы `double`, минимум, максимум, среднее, `printf`, `Locale.US`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Задача из дня про структуры и массивы в Java Bootcamp Школы 21.

Считай `N`, затем `N` вещественных чисел. Выведи минимум, максимум и среднее арифметическое — каждое с двумя знаками после точки:

```text
Min: <минимум>
Max: <максимум>
Avg: <среднее>
```

Не забудь `sc.useLocale(Locale.US)` и `System.out.printf(Locale.US, ...)`.

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3<br>1 2 3 | Min: 1.00<br>Max: 3.00<br>Avg: 2.00 |
| 2<br>-1 1 | Min: -1.00<br>Max: 1.00<br>Avg: 0.00 |
| 1<br>2.5 | Min: 2.50<br>Max: 2.50<br>Avg: 2.50 |
