Задача из дня про массивы в Java Bootcamp Школы 21.

Считай `N`, затем `N` целых чисел. Для каждого значения построй строку гистограммы: значение, двоеточие, пробел и столько символов `#`, сколько раз значение встретилось.

Выводи строки **по возрастанию значения**:

```text
<значение>: <##...>
```

```java
Map<Integer, Integer> counts = new TreeMap<>();
for (int i = 0; i < n; i++) {
    int value = sc.nextInt();
    counts.put(value, counts.getOrDefault(value, 0) + 1);
}
for (Map.Entry<Integer, Integer> entry : counts.entrySet()) {
    StringBuilder bar = new StringBuilder();
    for (int i = 0; i < entry.getValue(); i++) {
        bar.append('#');
    }
    System.out.println(entry.getKey() + ": " + bar);
}
```

`TreeMap` держит ключи отсортированными, поэтому дополнительная сортировка не нужна.

### Примеры

| 3<br>5 5 5 | 5: ### |
| 4<br>2 1 2 1 | 1: ##<br>2: ## |
