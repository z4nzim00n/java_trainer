# JAVA_12_04. Гистограмма — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат |
| --- | --- |
| `6` + `1 2 2 3 3 3` | `1: #\n2: ##\n3: ###\n` |
| `3` + `5 5 5` | `5: ###\n` |
| `4` + `2 1 2 1` | `1: ##\n2: ##\n` |
| `1` + `0` | `0: #\n` |

## Крайние случаи

- **Одно значение** — одна строка.
- **Повторы** — длина полосы равна частоте.
- **Порядок ввода** — не влияет, ключи сортированы.
- **Ноль как значение** — выводится первой строкой.
