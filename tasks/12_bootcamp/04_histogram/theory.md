# Разбор задания

## Подсчёт частот

Та же схема, что в задании про `HashMap`:

```java
counts.put(value, counts.getOrDefault(value, 0) + 1);
```

Но здесь важно вывести значения по возрастанию. `TreeMap` хранит ключи в отсортированном порядке (для `Integer` — по возрастанию), поэтому сразу подходит.

## Map.Entry

Итерация по парам:

```java
for (Map.Entry<Integer, Integer> entry : counts.entrySet()) {
    int value = entry.getKey();
    int count = entry.getValue();
}
```

`entrySet()` возвращает множество пар «ключ-значение».

## Повтор символа

В Java 8 нет `String.repeat` (он появился в Java 11). Повторяем вручную:

```java
StringBuilder bar = new StringBuilder();
for (int i = 0; i < count; i++) {
    bar.append('#');
}
```

`StringBuilder` не создаёт новую строку на каждом шаге, в отличие от `bar = bar + "#"`.

## Пустой ввод

По условию `N >= 1`, но если бы `N` было 0, цикл вывода просто не выполнился бы — корректный пустой вывод.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `HashMap` без сортировки | Порядок строк непредсказуем |
| `entry.getKey() == value` | Сравнение ссылок для `Integer` (в пределах кэша работает случайно) |
| Лишний пробел после `#` | Побайтовое сравнение не пройдёт |
| `count + " #"` один раз | Всегда один решёток |
| `String.repeat` | Нет в Java 8 |
