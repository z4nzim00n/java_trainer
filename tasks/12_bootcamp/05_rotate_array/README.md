## JAVA_12_05. Циклический сдвиг массива

### Задание
| Java_12_05 ||
| ------ | ------- |
| **Темы:** | Массивы, остаток от деления, циклический сдвиг. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай `N`, затем `K`, затем `N` целых чисел. Сдвинь массив **влево** на `K` позиций по кругу и выведи результат через пробел.

Пример: `1 2 3 4 5` при `K = 2` превращается в `3 4 5 1 2`.

Если `K` больше `N`, используй остаток: `K % N`. Сдвиг на `N` возвращает массив в исходное состояние.

```java
int shift = k % n;
for (int i = 0; i < n; i++) {
    int index = (i + shift) % n;
    // вывести a[index]
}
```

Гарантируется, что `N >= 1` и `K >= 0`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5 2<br>1 2 3 4 5 | 3 4 5 1 2 |
| 4 0<br>1 2 3 4 | 1 2 3 4 |
| 3 4<br>7 8 9 | 8 9 7 |
