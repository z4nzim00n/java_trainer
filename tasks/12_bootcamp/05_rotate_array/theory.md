# Разбор задания

## Сдвиг влево

При сдвиге влево элемент с индексом `i` переходит на позицию `i - shift`, но проще смотреть с другой стороны: на позицию `i` нового массива приходит элемент `(i + shift) % n` старого.

```text
a = [1, 2, 3, 4, 5], shift = 2
новый[0] = a[(0+2) % 5] = a[2] = 3
новый[1] = a[3] = 4
новый[2] = a[4] = 5
новый[3] = a[0] = 1
новый[4] = a[1] = 2
```

## Зачем остаток

`(i + shift)` может выйти за границу массива. `% n` заворачивает индекс в диапазон `0..n-1`.

Если `K = 4` и `N = 3`, фактический сдвиг `4 % 3 = 1`: четыре полных оборота на три дают один.

## Без второго массива

Можно вывести элементы в новом порядке, не создавая копию:

```java
for (int i = 0; i < n; i++) {
    int index = (i + shift) % n;
    if (i > 0) sb.append(' ');
    sb.append(a[index]);
}
```

Этого достаточно для вывода. Если нужно именно изменить массив, применяют тройной разворот или дополнительный массив.

## Крайние случаи

- `K = 0` — массив не меняется.
- `K > N` — работает благодаря `%`.
- `N = 1` — любой сдвиг даёт тот же единственный элемент.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `(i + shift)` без `% n` | Выход за границу массива |
| Сдвиг вправо | Порядок элементов обратный ожидаемому |
| `K` без нормализации | Для `K >= N` неверный индекс |
| Лишний пробел в конце | Тест не пройден |
| `shift = n % k` | Перепутаны местами `n` и `k` |
