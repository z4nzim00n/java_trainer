Задача из вводного дня Java Bootcamp Школы 21.

Считай целое `N` и выведи `true`, если это простое число, иначе `false`. Простое число больше `1` и делится только на `1` и на само себя.

Вынеси проверку в отдельный метод:

```java
static boolean isPrime(int n) {
    if (n < 2) {
        return false;
    }
    for (int d = 2; (long) d * d <= n; d++) {
        if (n % d == 0) {
            return false;
        }
    }
    return true;
}
```

Достаточно проверить делители до корня из `N`: если у числа есть делитель больше корня, то парный ему делитель меньше корня.

Гарантируется, что `0 <= N <= 2 000 000 000`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 7 | true |
| 2 | true |
| 1 | false |
| 9 | false |
