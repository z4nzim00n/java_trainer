# Разбор задания

## Определение

Простое число — натуральное число больше `1`, у которого ровно два делителя: `1` и оно само.

| Число | Простое? | Почему |
| --- | --- | --- |
| 0 | нет | меньше 2 |
| 1 | нет | только один делитель |
| 2 | да | первое простое |
| 9 | нет | 3 · 3 |
| 97 | да | нет делителей до √97 ≈ 9.8 |

## Перебор делителей

Наивно можно проверить все `d` от `2` до `n - 1`. Это O(N) и медленно. Достаточно дойти до √N:

Если `n = a · b` и `a <= b`, то `a <= √n`. Значит, любой составной `n` имеет делитель не больше корня.

```java
for (int d = 2; (long) d * d <= n; d++) {
    if (n % d == 0) return false;
}
```

Условие `d * d <= n` без приведения к `long` может переполниться при `d` около 46341 (квадрат больше `int`). Приведение `(long) d * d` безопасно.

## Ранний выход

Как только найден делитель, дальше проверять не нужно — `return false` сразу. Для простых чисел цикл пройдёт все делители до корня — это O(√N).

## Метод isPrime

Вынесение в статический метод делает код читаемым и тестируемым. Метод `static`, потому что ему не нужно состояние объекта.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| Не обработать `n < 2` | 0 и 1 считаются простыми |
| Цикл до `n - 1` | Работает, но медленно |
| `d * d <= n` без `long` | Переполнение на больших n |
| Проверять чётность отдельно | Работает, но не обязательно |
| `n % d = 0` | Присваивание вместо сравнения |
