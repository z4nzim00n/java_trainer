# Разбор задания

## Два независимых потока

```java
Thread evenThread = new Thread(new Runnable() {
    @Override
    public void run() {
        for (int i = 2; i <= n; i += 2) {
            evenSum[0] += i;
        }
    }
});
```

Каждый поток работает со своей ячейкой результата. Общих изменяемых переменных нет — синхронизация не требуется.

## join обоих

```java
evenThread.start();
oddThread.start();
evenThread.join();
oddThread.join();
```

Порядок `join` не важен: ждём завершения обоих. Если дождаться только одного, второй результат может быть ещё не готов.

## Чётность

| Проверка | Когда истинна |
| --- | --- |
| `i % 2 == 0` | чётное |
| `i % 2 == 1` | нечётное |

В цикле можно идти с шагом 2: `for (int i = 2; ...; i += 2)`. Это быстрее, чем проверять каждое число.

## Суммы

Для `N = 10`:

- чётные: 2 + 4 + 6 + 8 + 10 = 30;
- нечётные: 1 + 3 + 5 + 7 + 9 = 25.

Сумма всех чисел 55, что совпадает с 30 + 25.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `join()` только у одного потока | Второй результат может быть не готов |
| Общий счётчик для сумм | Возможна потеря обновлений без синхронизации |
| `i += 1` с проверкой чётности | Работает, но медленнее |
| `int` для сумм | Переполнение при больших N |
| Забыть `start()` | Поток не выполнится вовсе |
