## JAVA_11_02. Два потока

### Задание
| Java_11_02 ||
| ------ | ------- |
| **Темы:** | Несколько потоков, независимые данные, `join()` для обоих. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай целое `N`. Запусти **два** потока:

- первый считает сумму чётных чисел от `1` до `N`;
- второй — сумму нечётных чисел от `1` до `N`.

Дождись завершения обоих и выведи:

```text
even: <сумма чётных>
odd: <сумма нечётных>
```

Каждый поток пишет в свою ячейку массива, поэтому общих изменяемых данных нет и гонки не возникает. `join()` нужен для обоих потоков.

Гарантируется, что `1 <= N <= 1 000 000`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 10 | even: 30<br>odd: 25 |
| 1 | even: 0<br>odd: 1 |
| 5 | even: 6<br>odd: 9 |
