# JAVA_11_04. Пул потоков и Future — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `3` + `1 2 3` | `14\n` | 1+4+9 |
| `1` + `5` | `25\n` | 25 |
| `4` + `-1 2 -3 4` | `30\n` | 1+4+9+16 |
| `2` + `0 0` | `0\n` | Нули |

## Крайние случаи

- **Отрицательные числа** — квадрат положительный.
- **Ноль** — 0.
- **Одно число** — результат равен квадрату.
- **Много чисел** — пул из двух потоков выполняет задачи по очереди.
