## JAVA_11_03. Синхронизированный счётчик

### Задание
| Java_11_03 ||
| ------ | ------- |
| **Темы:** | Гонка данных, `synchronized`, атомарность. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Опиши **package-private** класс `Counter`:

```java
class Counter {
    private int value;

    synchronized void increment() {
        value++;
    }

    int get() {
        return value;
    }
}
```

Считай `K`. Запусти **два** потока, каждый из которых вызывает `increment()` ровно `K` раз. Дождись обоих и выведи значение счётчика — оно должно быть ровно `2 * K`.

Без `synchronized` операция `value++` не атомарна: два потока могут прочитать одно и то же значение и потерять одно обновление. Результат стал бы меньше ожидаемого и менялся бы от запуска к запуску.

Гарантируется, что `0 <= K <= 100 000`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------- |
| 1000 | 2000 |
| 1 | 2 |
| 0 | 0 |
