# JAVA_11_03. Синхронизированный счётчик — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `1000` | `2000\n` | Два потока по 1000 |
| `1` | `2\n` | Минимальный ненулевой случай |
| `0` | `0\n` | Потоки ничего не делают |
| `100000` | `200000\n` | Нагрузочный случай |

## Крайние случаи

- **K = 0** — итог 0, потоки завершаются сразу.
- **K = 1** — итог 2; именно здесь гонка проявляется редко, но синхронизация всё равно нужна.
- **Большое K** — проверяет стабильность под нагрузкой.
