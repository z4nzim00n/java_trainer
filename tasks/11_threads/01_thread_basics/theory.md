# Разбор задания

## Поток

`Thread` — единица выполнения внутри процесса. Потоки делят память, поэтому могут обмениваться данными через общие переменные.

## Runnable

```java
Runnable task = new Runnable() {
    @Override
    public void run() {
        // код, который выполнится в новом потоке
    }
};
Thread thread = new Thread(task);
```

`Runnable` — функциональный интерфейс с единственным методом `run()`.

## start против run

| Вызов | Что происходит |
| --- | --- |
| `thread.start()` | создаётся новый поток, в нём вызывается `run()` |
| `thread.run()` | обычный вызов метода в текущем потоке, без параллельности |

## join

```java
thread.join();
```

Ждёт завершения потока. Без `join()` основной поток мог бы напечатать `result[0]` раньше, чем рабочий поток его заполнит.

`join()` объявляет `throws InterruptedException` — checked-исключение. В учебном коде достаточно:

```java
try {
    thread.join();
} catch (InterruptedException e) {
    Thread.currentThread().interrupt();
}
```

Восстановление флага прерывания — правильная привычка: оно сообщает внешнему коду, что поток просили остановить.

## Почему массив из одного элемента

Локальная переменная, захваченная анонимным классом, должна быть `final` (или effectively final). Присвоить ей значение из другого потока нельзя. Массив — объект: ссылка `final`, а содержимое менять можно:

```java
final long[] result = new long[1];
result[0] = 42;
```

Альтернативы — `AtomicLong` или `Future`, но для первого знакомства массив нагляднее.

## Видимость изменений

`join()` создаёт отношение «happens-before»: всё, что сделал рабочий поток до завершения, видно основному после `join()`. Без синхронизации чтение общего поля из другого потока не гарантировано.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `thread.run()` | Нет нового потока, код выполняется последовательно |
| Нет `join()` | Результат может быть напечатан до вычисления |
| Присвоение локальной переменной из `run()` | Ошибка компиляции: переменная не effectively final |
| Игнорирование `InterruptedException` | Ошибка компиляции |
| `sum` в `int` для больших N | Возможно переполнение |
