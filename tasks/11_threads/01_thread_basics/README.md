## JAVA_11_01. Первый поток

### Задание
| Java_11_01 ||
| ------ | ------- |
| **Темы:** | `Thread`, `Runnable`, `start()`, `join()`, `InterruptedException`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай целое `N`. Создай отдельный поток, который вычислит сумму чисел от `1` до `N`, дождись его завершения через `join()` и выведи результат.

```java
final int n = sc.nextInt();
final long[] result = new long[1];
Thread thread = new Thread(new Runnable() {
    @Override
    public void run() {
        long sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        result[0] = sum;
    }
});
thread.start();
thread.join();
System.out.println(result[0]);
```

Важно: `start()` запускает новый поток, а прямой вызов `run()` выполнил бы код в текущем потоке. `join()` блокирует вызывающий поток, пока рабочий не завершится, — только после этого можно читать результат.

Гарантируется, что `1 <= N <= 1 000 000`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 100 | 5050 |
| 1 | 1 |
| 10 | 55 |
