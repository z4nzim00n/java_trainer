## JAVA_09_01. Безопасное деление

### Задание
| Java_09_01 ||
| ------ | ------- |
| **Темы:** | `try`/`catch`, `ArithmeticException`, обработка ошибок. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай два целых числа `a` и `b` и выведи результат целочисленного деления `a / b`.

Если `b` равно нулю, деление целых чисел в Java выбрасывает `ArithmeticException`. Не дай программе упасть: перехвати исключение и выведи

```text
Error: division by zero
```

Используй `try`/`catch`:

```java
try {
    System.out.println(a / b);
} catch (ArithmeticException e) {
    System.out.println("Error: division by zero");
}
```

Гарантируется, что на вход подаются два корректных целых числа.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 10 2 | 5 |
| 7 2 | 3 |
| 5 0 | Error: division by zero |
| -9 3 | -3 |
