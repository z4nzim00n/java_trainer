# JAVA_09_01. Безопасное деление — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `10 2` | `5\n` | Обычное деление |
| `7 2` | `3\n` | Целочисленное деление, дробь отброшена |
| `5 0` | `Error: division by zero\n` | `ArithmeticException` перехвачен |
| `-9 3` | `-3\n` | Отрицательное делимое |
| `0 5` | `0\n` | Ноль в делимом |

## Крайние случаи

- **Делитель 0** — главный случай: без `catch` программа упадёт.
- **Нецелый результат** — отбрасывается, это деление `int`.
- **Отрицательные числа** — усечение к нулю.
- **Ноль в делимом** — допустим, результат 0.
