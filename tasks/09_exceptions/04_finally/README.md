## JAVA_09_04. Блок finally

### Задание
| Java_09_04 ||
| ------ | ------- |
| **Темы:** | `try`/`catch`/`finally`, гарантированное выполнение кода. |
| **Файл решения:** | Main.java |
| **Входные данные** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай два целых числа и выведи результат целочисленного деления. Если делитель равен нулю, выведи `Error: division by zero`.

Независимо от того, было исключение или нет, в конце должна быть выведена строка `Done` — для этого используй `finally`.

```java
try {
    System.out.println(a / b);
} catch (ArithmeticException e) {
    System.out.println("Error: division by zero");
} finally {
    System.out.println("Done");
}
```

Порядок строк в выводе:

- при успехе: результат, затем `Done`;
- при ошибке: сообщение, затем `Done`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 10 2 | 5<br>Done |
| 5 0 | Error: division by zero<br>Done |
| 7 2 | 3<br>Done |
