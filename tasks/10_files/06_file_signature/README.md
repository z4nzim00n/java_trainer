## JAVA_10_06. Сигнатура файла

| **Выходные данные** | Стандартный поток вывода (stdout) |

Задача из дня про файлы в Java Bootcamp Школы 21: определить тип файла по его **сигнатуре** — первым байтам.

Поддержи три формата:

| Тип | Первые байты | Вывод |
| --- | --- | --- |
| PNG | `89 50 4E 47` (`\x89PNG`) | `PNG` |
| PDF | `25 50 44 46` (`%PDF`) | `PDF` |
| ZIP | `50 4B 03 04` (`PK\x03\x04`) | `ZIP` |
| всё остальное | — | `UNKNOWN` |

```java
byte[] data = Files.readAllBytes(Paths.get(args[0]));
if (data.length >= 4
        && (data[0] & 0xFF) == 0x89
        && data[1] == 'P' && data[2] == 'N' && data[3] == 'G') {
    System.out.println("PNG");
}
```

Обрати внимание на `data[0] & 0xFF`: `byte` в Java знаковый, и `0x89` хранится как отрицательное число. Побитовое «И» с `0xFF` превращает его в `137`.

### Примеры

| Содержимое файла | Результат работы |
| ------ | ------ |
| начинается с `\x89PNG` | PNG |
| начинается с `%PDF-1.4` | PDF |
| начинается с `PK\x03\x04` | ZIP |
| текстовый файл | UNKNOWN |
| пустой файл | UNKNOWN |
