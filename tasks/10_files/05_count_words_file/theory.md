# Разбор задания

## readAllLines

```java
List<String> lines = Files.readAllLines(path, StandardCharsets.UTF_8);
```

Метод читает файл и возвращает список строк **без** символов перевода строки. Удобно для небольших файлов; для больших лучше `Files.lines` (поток) или `BufferedReader`.

## Подсчёт слов

```java
line = line.trim();
if (!line.isEmpty()) {
    count += line.split("\\s+").length;
}
```

- `trim()` убирает пробелы по краям;
- пустую строку пропускаем: `"".split("\\s+")` вернул бы массив из одного пустого элемента;
- `\\s+` — один или несколько пробельных символов, поэтому несколько пробелов не создают пустых слов.

## Альтернатива на Scanner

```java
Scanner file = new Scanner(Paths.get(args[0]), "UTF-8");
int count = 0;
while (file.hasNext()) {
    file.next();
    count++;
}
```

`Scanner.next()` сам пропускает любые пробельные символы. Это короче, но в задании тренируется работа со строками.

## Кодировка

Если файл в UTF-8, а читать системной кодировкой на русской Windows (обычно Cp1251), кириллица превратится в «кракозябры». Количество слов при этом может не измениться, но лучше всегда указывать UTF-8 явно.

## Обработка ошибок

`readAllLines` объявляет `throws IOException`. Можно объявить `throws` в `main` или обернуть в `try`/`catch`. В эталоне используется `throws` — для учебной программы этого достаточно.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `split(" ")` | Несколько пробелов дают пустые элементы |
| Нет проверки пустой строки | Пустые строки добавляют по 1 |
| Считать символы вместо слов | Другой результат |
| Забыть кодировку | Проблемы с кириллицей |
| `line.length()` как количество слов | Это длина строки |
