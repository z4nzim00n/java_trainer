## JAVA_10_04. Сумма чисел из файла

### Задание
| Java_10_04 ||
| ------ | ------- |
| **Темы:** | Чтение файла через `Scanner`, суммирование, `while (hasNextInt())`. |
| **Файл решения:** | Main.java |
| **Входные данные** | Путь к файлу — первый аргумент командной строки |
| **Выходные данные** | Стандартный поток вывода (stdout) |

В файле записаны целые числа, разделённые пробелами и/или переносами строк. Считай их все и выведи сумму.

```java
Scanner file = new Scanner(Paths.get(args[0]), "UTF-8");
long sum = 0;
while (file.hasNextInt()) {
    sum += file.nextInt();
}
System.out.println(sum);
```

`Scanner` умеет читать не только `System.in`, но и файл. Метод `hasNextInt()` проверяет, есть ли следующее число, не «съедая» его.

Пустой файл даёт сумму `0`.

### Примеры

| Содержимое файла | Результат работы |
| ------ | ------ |
| `1 2 3` | 6 |
| `10 20 -5` | 25 |
| `0` | 0 |
| (пустой файл) | 0 |
