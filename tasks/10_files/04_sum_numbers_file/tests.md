# JAVA_10_04. Сумма чисел из файла — Тесты

## Компиляция и запуск

```bash
javac -encoding UTF-8 Main.java
printf '1 2 3\n' > /tmp/nums.txt
java Main /tmp/nums.txt
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java
java Solution /tmp/nums.txt
```

## Проверка вывода

| Файл | Результат |
| --- | --- |
| `1 2 3` | `6\n` |
| `10 20 -5` | `25\n` |
| числа в столбик `4\n5\n6` | `15\n` |
| пустой файл | `0\n` |

## Крайние случаи

- **Пустой файл** — сумма 0.
- **Отрицательные числа** — учитываются со знаком.
- **Разные разделители** — пробелы и переносы строк равнозначны для `Scanner`.
- **Ноль** — не меняет сумму.
