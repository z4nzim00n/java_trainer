# Разбор задания

## Files.copy

```java
Files.copy(source, target, options...)
```

Копирует содержимое файла. Без опций:

- если целевой файл существует — `FileAlreadyExistsException`;
- если родительская папка не существует — `NoSuchFileException`.

## StandardCopyOption

| Опция | Значение |
| --- | --- |
| `REPLACE_EXISTING` | перезаписать цель, если она есть |
| `COPY_ATTRIBUTES` | скопировать метаданные (время, права) |
| `NOFOLLOW_LINKS` | копировать саму ссылку, а не то, на что она указывает |

В задании нужна `REPLACE_EXISTING`: тесты могут запускаться повторно, и файл назначения уже существует.

## Атомарность

`Files.copy` не гарантирует атомарность: при сбое в середине целевой файл может остаться частично записанным. Для временных файлов часто копируют в `*.tmp` и затем переименовывают.

## Ошибки

| Исключение | Когда |
| --- | --- |
| `NoSuchFileException` | исходного файла нет |
| `FileAlreadyExistsException` | цель существует, а `REPLACE_EXISTING` не указан |
| `IOException` | общая ошибка ввода-вывода |

Все они — подтипы `IOException`, поэтому достаточно одного `catch (IOException e)`.

## Проверка копии

```bash
cmp /tmp/source.txt /tmp/dest.txt
```

`cmp` молча завершается успешно, если файлы совпадают побайтово. Это лучшая проверка копирования.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| Нет `REPLACE_EXISTING` | Повторный запуск падает |
| Перепутаны аргументы | Копирование не туда |
| `Files.move` | Перемещает, а не копирует: источник исчезает |
| Не обработан `IOException` | Ошибка компиляции |
| Сравнение размера вместо содержимого | Не доказывает идентичность |
