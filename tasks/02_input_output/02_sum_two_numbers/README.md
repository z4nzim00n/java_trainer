## JAVA_02_02. Сумма двух чисел

### Задание
| Java_02_02 ||
| ------ | ------- |
| **Темы:** | Несколько вызовов `nextInt`, арифметика, ввод на одной и нескольких строках. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Считай два целых числа и выведи их сумму с переносом строки. Числа могут быть разделены пробелом, табуляцией или переводом строки — `Scanner` сам пропускает разделители.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2 3 | 5 |
| -4 4 | 0 |
| 10 20 | 30 |
