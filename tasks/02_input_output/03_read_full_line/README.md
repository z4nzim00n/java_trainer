## JAVA_02_03. Чтение строки целиком

### Задание
| Java_02_03 ||
| ------ | ------- |
| **Темы:** | `nextLine`, `next`, разница между чтением слова и строки. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Считай **всю строку** целиком, включая пробелы внутри, и выведи её обратно с переносом строки в конце. Строка может содержать несколько слов, лишние пробелы и стоять без завершающего перевода строки.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Hello world | Hello world |
|   spaced  |   spaced   |
| a | a |
