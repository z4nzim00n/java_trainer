## JAVA_02_01. Эхо-число

### Задание
| Java_02_01 ||
| ------ | ------- |
| **Темы:** | `Scanner`, `System.in`, `nextInt`, стандартный ввод. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Считай одно целое число со стандартного ввода и выведи его обратно с переносом строки.

Это первое задание с вводом: разберись, как `Scanner` читает данные из `System.in`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 42 | 42 |
| -7 | -7 |
| 0 | 0 |
