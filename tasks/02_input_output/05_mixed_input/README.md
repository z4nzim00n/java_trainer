## JAVA_02_05. Число и строка вместе

### Задание
| Java_02_05 ||
| ------ | ------- |
| **Темы:** | Комбинация `nextInt` и `nextLine`, «съеденный» перевод строки. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Сначала считай целое число `age`, затем — строку `name` целиком (имя может состоять из нескольких слов). Выведи:

```text
Alice Smith: 25
```

То есть `<name>: <age>` с переносом строки. Ввод устроен так: первая строка — число, вторая — имя.

Здесь есть ловушка: после `nextInt()` в потоке остаётся перевод строки, и `nextLine()` вернёт пустую строку, если его не «съесть». Разберись, как это исправить.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 25<br>Alice Smith | Alice Smith: 25 |
| 5<br>Bob | Bob: 5 |
