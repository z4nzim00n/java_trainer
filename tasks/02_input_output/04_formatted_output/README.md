## JAVA_02_04. Форматированный вывод

### Задание
| Java_02_04 ||
| ------ | ------- |
| **Темы:** | `printf`, спецификаторы формата, округление, `Locale`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Считай вещественную цену `price` и целое количество `count`. Выведи итоговую стоимость в формате:

```text
Total: 7.00
```

То есть строка `Total: `, значение `price * count` с **ровно двумя знаками после точки** и перевод строки. Используй `System.out.printf`.

> Дробная часть всегда печатается с точкой, поэтому формат нужно задать с `Locale.US`: на русской системе `printf` по умолчанию использует запятую.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3.5 2 | Total: 7.00 |
| 0.1 3 | Total: 0.30 |
| 10 1 | Total: 10.00 |
