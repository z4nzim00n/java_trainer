## JAVA_03_01. Площадь круга

### Задание
| Java_03_01 ||
| ------ | ------- |
| **Темы:** | Тип `double`, `Scanner.nextDouble`, `Math.PI`, арифметические выражения, `printf`, `Locale.US`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает радиус круга (одно вещественное число) и вычисляет его площадь по формуле:

```text
S = PI * r * r
```

Используй константу `Math.PI` — не подставляй `3.14` вручную.

Результат выведи с **ровно двумя знаками после десятичной точки** и переносом строки в конце:

```java
System.out.printf(Locale.US, "%.2f\n", area);
```

Чтобы число считывалось и печаталось с точкой (а не с запятой, как принято на русской Windows), обязательно вызови `sc.useLocale(Locale.US)` после создания `Scanner`.

Гарантируется, что на вход подаётся корректное неотрицательное число.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 1 | 3.14 |
| 2 | 12.57 |
| 0 | 0.00 |
