# Разбор задания

## Вещественные числа: double

В C ты уже знаком с `double`. В Java всё похоже: `double` — 64-битное число с плавающей точкой, литералы пишутся с точкой (`3.5`, `0.0`). Целочисленный литерал (`2`) в выражении с `double` автоматически повышается до `double` — как в C.

```java
double radius = sc.nextDouble();   // считали вещественное число
double area = Math.PI * radius * radius;
```

## Math.PI

Не нужно писать `3.14` или `3.14159` руками — в стандартной библиотеке есть готовая константа:

| Запись | Что это |
| --- | --- |
| `Math.PI` | `3.141592653589793` (максимально точное значение π для `double`) |
| `3.14` | грубое приближение: для r = 2 даст 12.56 вместо 12.57 |

`Math` — класс из `java.lang`, импортировать его не нужно.

## Почему printf, а не println

`System.out.println(area)` напечатает всё число целиком: `12.566370614359172`. А нужно ровно два знака после точки. Для этого есть форматный вывод (аналог `printf` в C):

```java
System.out.printf(Locale.US, "%.2f\n", area);
```

| Элемент | Значение |
| --- | --- |
| `%f` | вывод вещественного числа |
| `.2` | ровно 2 знака после десятичной точки, с округлением |
| `\n` | перенос строки в конце (обязателен по условию!) |
| `Locale.US` | десятичный разделитель — точка |

Округление идёт по обычным правилам: `12.566...` → `12.57`, `3.1415...` → `3.14`.

## Ловушка русской Windows: Locale

На русской локали `Scanner.nextDouble()` ожидает запятую (`3,5`), а `printf("%f")` печатает запятую. Тесты подают числа с точкой и ждут точку в ответе. Поэтому:

```java
Scanner sc = new Scanner(System.in);
sc.useLocale(Locale.US);              // читаем с точкой
System.out.printf(Locale.US, "%.2f\n", area);  // печатаем с точкой
```

Не забудь импорт: `import java.util.Locale;`.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `int radius = sc.nextInt()` | Дробный радиус (`1.5`) не считается или обрежется |
| `3.14 * r * r` вместо `Math.PI` | Неточный результат: для r = 2 выйдет 12.56, а не 12.57 |
| `println(area)` | Печатает много лишних знаков: `12.566370614359172` |
| `printf("%.2f", area)` без `\n` | Нет переноса строки в конце — тест не пройден |
| Нет `useLocale(Locale.US)` | На русской Windows ввод `3.5` вызовет ошибку, а вывод будет с запятой |
| `Math.PI()` | `PI` — константа (поле), а не метод: скобки не нужны |
