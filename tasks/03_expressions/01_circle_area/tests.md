# JAVA_03_01. Площадь круга — Тесты

## Компиляция

Для проверки собственного решения:

```bash
javac -encoding UTF-8 Main.java
java Main
```

Для проверки эталона:

```bash
javac -encoding UTF-8 Solution.java
java Solution
```

Для проверки комментированной версии:

```bash
javac -encoding UTF-8 SolutionCommented.java
java SolutionCommented
```

> Это отдельные программы. Собирайте только один файл за раз.

## Проверка вывода

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `1` | `3.14\n` | `echo "1" \| java Main` | π·1·1 = 3.14159... → 3.14 |
| `2` | `12.57\n` | `echo "2" \| java Main` | π·4 = 12.56637... → округление вверх до 12.57 |
| `0` | `0.00\n` | `echo "0" \| java Main` | Нулевой радиус: площадь 0, но формат требует два знака |
| `1.5` | `7.07\n` | `echo "1.5" \| java Main` | Дробный радиус: π·2.25 = 7.06858... → 7.07 |

## Крайние случаи

- **Радиус 0** — ответ `0.00`, а не `0` и не `0.0`: формат `%.2f` всегда печатает ровно два знака.
- **Дробный радиус** — число должно считываться как `double`, а не `int`.
- **EOF без `\n`** — `echo` добавляет перенос, но `Scanner` прекрасно читает число и без него: `printf '2' | java Main` тоже работает.
- **Запятая вместо точки** — на русской Windows без `useLocale(Locale.US)` ввод `1.5` приведёт к исключению `InputMismatchException`.

## Как увидеть точные байты

```bash
echo "2" | java Main | od -An -t x1
```

Ожидаемые байты: `31 32 2e 35 37 0a` — это `12.57` и `\n` (`0a`). Байт `2e` — точка: если там `2c` (запятая), значит забыт `Locale.US`.
