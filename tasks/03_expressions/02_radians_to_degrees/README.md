## JAVA_03_02. Радианы в градусы

### Задание
| Java_03_02 ||
| ------ | ------- |
| **Темы:** | Тип `double`, `Scanner.nextDouble`, `Math.PI`, арифметические выражения, `printf`, `Locale.US`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает угол в радианах (одно вещественное число) и переводит его в градусы по формуле:

```text
degrees = radians * 180 / PI
```

Используй константу `Math.PI`.

Результат выведи с **ровно двумя знаками после десятичной точки** и переносом строки в конце:

```java
System.out.printf(Locale.US, "%.2f\n", degrees);
```

Не забудь `sc.useLocale(Locale.US)` после создания `Scanner`, чтобы числа читались и печатались с точкой.

Гарантируется, что на вход подаётся корректное число.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3.141592653589793 | 180.00 |
| 0 | 0.00 |
| 1.5707963267948966 | 90.00 |
