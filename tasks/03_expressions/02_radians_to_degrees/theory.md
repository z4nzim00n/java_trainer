# Разбор задания

## Радианы и градусы

В математике углы часто измеряют в радианах: полный оборот — это `2π` радиан, развёрнутый угол — `π` радиан = `180°`. Отсюда формула перевода:

```text
degrees = radians * 180 / PI
```

Проверка на известных значениях:

| Радианы | Градусы |
| --- | --- |
| `0` | 0° |
| `π / 2 ≈ 1.5707963267948966` | 90° |
| `π ≈ 3.141592653589793` | 180° |
| `2π ≈ 6.283185307179586` | 360° |

## Порядок вычислений

Умножение и деление имеют одинаковый приоритет и выполняются **слева направо**:

```java
double degrees = radians * 180 / Math.PI;   // (radians * 180) / Math.PI
```

Можно было бы написать `radians * (180 / Math.PI)` — результат тот же, потому что `Math.PI` имеет тип `double`, и деление сразу вещественное. Но если написать `180 / Math.PI` — всё в порядке, а вот `180 / 3` было бы целочисленным делением (об этом — отдельное задание про ловушку деления). Здесь ловушки нет: `Math.PI` — `double`, поэтому любое выражение с ним считается в `double`.

Целочисленный литерал `180` в выражении с `double` автоматически повышается до `double` — как в C. Писать `180.0` не обязательно, но и не ошибка.

## Форматный вывод

```java
System.out.printf(Locale.US, "%.2f\n", degrees);
```

| Элемент | Значение |
| --- | --- |
| `%.2f` | вещественное число с ровно 2 знаками после точки, с округлением |
| `\n` | перенос строки в конце (обязателен по условию) |
| `Locale.US` | десятичный разделитель — точка, а не запятая |

`180.0` напечатается как `180.00` — формат всегда добавляет два знака, даже если число целое.

## Locale: точка против запятой

На русской Windows `Scanner.nextDouble()` по умолчанию ждёт запятую, а `printf` печатает запятую. Тесты работают с точкой, поэтому обязательны обе меры:

```java
sc.useLocale(Locale.US);                       // чтение с точкой
System.out.printf(Locale.US, "%.2f\n", ...);   // печать с точкой
```

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `radians * 180 / 3.14` | Неточная константа: для π на вводе выйдет не ровно 180.00 |
| `int radians = sc.nextInt()` | Дробное значение не считается: `InputMismatchException` |
| `println(degrees)` | Лишние знаки: `180.0` вместо `180.00` |
| `printf("%.2f", degrees)` без `\n` | Нет переноса строки — тест не пройден |
| Нет `useLocale(Locale.US)` | На русской Windows ввод с точкой падает с исключением |
| `Math.PI()` со скобками | `PI` — константа, а не метод: ошибка компиляции |
