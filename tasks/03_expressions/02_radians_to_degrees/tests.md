# JAVA_03_02. Радианы в градусы — Тесты

## Компиляция

Для проверки собственного решения:

```bash
javac -encoding UTF-8 Main.java
java Main
```

Для проверки эталона:

```bash
javac -encoding UTF-8 Solution.java
java Solution
```

Для проверки комментированной версии:

```bash
javac -encoding UTF-8 SolutionCommented.java
java SolutionCommented
```

> Это отдельные программы. Собирайте только один файл за раз.

## Проверка вывода

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `3.141592653589793` | `180.00\n` | `echo "3.141592653589793" \| java Main` | π радиан = ровно 180° |
| `0` | `0.00\n` | `echo "0" \| java Main` | Ноль радиан = 0°, формат требует два знака |
| `1.5707963267948966` | `90.00\n` | `echo "1.5707963267948966" \| java Main` | π/2 радиан = 90° |
| `-3.141592653589793` | `-180.00\n` | `echo "-3.141592653589793" \| java Main` | Отрицательный угол тоже переводится |

## Крайние случаи

- **Ноль** — ответ `0.00`, а не `0`: формат `%.2f` всегда печатает два знака.
- **Отрицательные радианы** — формула работает без изменений, знак сохраняется.
- **EOF без `\n`** — `printf '0' | java Main` работает так же, как `echo`: `Scanner` не требует переноса после числа.
- **Запятая вместо точки** — без `useLocale(Locale.US)` ввод `1.5` на русской Windows вызовет `InputMismatchException`.

## Как увидеть точные байты

```bash
echo "0" | java Main | od -An -t x1
```

Ожидаемые байты: `30 2e 30 30 0a` — это `0.00` и `\n` (`0a`). Байт `2e` — точка: если там `2c` (запятая), значит забыт `Locale.US`.
