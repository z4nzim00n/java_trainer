# Разбор задания

## Как достать цифры числа арифметикой

В C ты уже видел этот приём: деление и остаток позволяют «разобрать» число на цифры без всяких строк.

| Операция | Что делает | Пример: n = 1234 |
| --- | --- | --- |
| `n / 1000` | целочисленное деление: отбрасывает всё после тысячи → первая цифра | `1` |
| `n % 10` | остаток от деления на 10 → последняя цифра | `4` |
| `n % 1000` | отбрасывает первую цифру | `234` |
| `(n % 1000) / 10` | отбрасывает ещё и последнюю → две средние цифры | `23` |

Ключевой момент: `/` между двумя `int` — **целочисленное** деление, дробная часть просто отбрасывается (не округляется!). `1234 / 1000` — это `1`, а не `1.234`.

## Как собрать число обратно

Позиция цифры в числе задаётся множителем:

```text
результат = last * 1000 + middle * 10 + first
```

Для `1234`: `4 * 1000 + 23 * 10 + 1 = 4000 + 230 + 1 = 4231`.

Разбор по шагам для `5678`:

| Шаг | Выражение | Значение |
| --- | --- | --- |
| Первая цифра | `5678 / 1000` | `5` |
| Последняя цифра | `5678 % 10` | `8` |
| Середина | `(5678 % 1000) / 10` | `67` |
| Сборка | `8 * 1000 + 67 * 10 + 5` | `8675` |

## Почему 1000 даёт 1, а не 0001

После обмена `1000` превращается в `0001`. Но результат — тип `int`, а у целых чисел не бывает ведущих нулей: `0001` и `1` — это одно и то же число. `System.out.println(1)` печатает `1`. Если бы задача требовала сохранить четыре знака (`0001`), пришлось бы печатать строку или использовать `printf("%04d")` — но здесь этого не нужно.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `n / 1000.0` | Деление становится вещественным: `1.234` вместо `1`, тип уже не `int` |
| `n % 100` вместо `(n % 1000) / 10` | Это две **последние** цифры (`34`), а не средние (`23`) |
| `middle * 100` | Середина сдвигается на разряд влево: `42301` вместо `4231` |
| Попытка напечатать `0001` для `1000` | `int` не хранит ведущие нули — правильный ответ `1` |
| `sc.nextDouble()` | Радиус ни при чём: число целое, нужен `nextInt()` |
| `print` вместо `println` | Нет переноса строки в конце — тест не пройден |
