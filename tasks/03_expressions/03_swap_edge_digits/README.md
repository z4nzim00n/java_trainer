## JAVA_03_03. Обмен крайних цифр

### Задание
| Java_03_03 ||
| ------ | ------- |
| **Темы:** | Тип `int`, `Scanner.nextInt`, целочисленное деление `/`, остаток `%`, арифметические выражения. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает четырёхзначное целое число и меняет местами его первую и последнюю цифры. Результат выведи как целое число с переносом строки в конце (`System.out.println`).

Гарантируется, что на вход подаётся целое число от `1000` до `9999`.

Подсказка: цифры числа можно достать арифметикой, без строк:

- первая цифра: `n / 1000`;
- последняя цифра: `n % 10`;
- две средние цифры как число: `(n % 1000) / 10`.

Пример: `1234` → первая `1`, последняя `4`, середина `23` → собираем `4` `23` `1` = `4231`.

Важно: результат — именно число (`int`), а не строка. Если после обмена впереди оказываются нули, они отбрасываются: `1000` → `0001` → печатается как `1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 1234 | 4231 |
| 1000 | 1 |
| 9999 | 9999 |
| 5678 | 8675 |
