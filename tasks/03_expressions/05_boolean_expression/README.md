## JAVA_03_05. Логическое выражение

### Задание
| Java_03_05 ||
| ------ | ------- |
| **Темы:** | Тип `boolean`, операторы сравнения, `&&`, `||`, `!`, `%`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает одно целое число `n` и выводит `true`, если выполняется **хотя бы одно** из условий:

- число делится на `3` нацело;
- последняя цифра числа равна `7`.

Иначе выведи `false`. В конце строки — перенос.

Подсказки:

- делимость проверяется остатком: `n % 3 == 0`;
- последняя цифра — тоже остаток: `n % 10 == 7`;
- объединить условия можно оператором `||` (логическое ИЛИ).

```java
boolean special = n % 3 == 0 || n % 10 == 7;
System.out.println(special);
```

`System.out.println` для `boolean` печатает ровно `true` или `false`.

Гарантируется, что `n` неотрицательно.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 9 | true |
| 17 | true |
| 10 | false |
| 21 | true |
