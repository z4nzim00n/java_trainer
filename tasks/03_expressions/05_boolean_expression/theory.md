# Разбор задания

## Тип boolean

В Java есть отдельный тип для истины и лжи:

```java
boolean ok = true;
boolean no = false;
```

В отличие от C, числа **не** считаются логическими значениями: `if (1)` не скомпилируется. В условии должно быть именно выражение типа `boolean`.

## Операторы сравнения

| Оператор | Значение |
| --- | --- |
| `==` | равно |
| `!=` | не равно |
| `<`, `<=`, `>`, `>=` | порядок |

Важно: `==` — это сравнение, а `=` — присваивание. Перепутать их в Java сложнее, чем в C: `if (x = 5)` просто не скомпилируется, потому что `int` не является `boolean`.

## Логические операторы

| Оператор | Значение | Пример |
| --- | --- | --- |
| `&&` | И | `a > 0 && a < 10` |
| `\|\|` | ИЛИ | `a == 0 \|\| a == 1` |
| `!` | НЕ | `!found` |

`&&` и `||` вычисляются **лениво** (short-circuit): если левая часть уже решила исход, правая не вычисляется.

```java
if (b != 0 && a / b > 2) { ... }  // деления на 0 не будет, если b == 0
```

## Приоритет

От высокого к низкому:

```text
!   →   < <= > >=   →   == !=   →   &&   →   ||
```

Сомневаешься — ставь скобки: `(n % 3 == 0) || (n % 10 == 7)`.

## Разбор условий задачи

| Условие | Выражение |
| --- | --- |
| делится на 3 | `n % 3 == 0` |
| оканчивается на 7 | `n % 10 == 7` |
| хотя бы одно | `... \|\| ...` |

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `n % 3 == 0 && n % 10 == 7` | `&&` требует оба условия сразу — логика неверна |
| `n / 3 == 0` | Это «n меньше 3», а не делимость |
| `if (n % 3)` | В Java нет неявного `int → boolean` |
| `println("true")` | Печатает строку, но путает регистр и не вычисляет условие |
