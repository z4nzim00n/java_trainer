# JAVA_03_05. Логическое выражение — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон и комментарии проверяются так же, отдельными файлами:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `9` | `true\n` | Делится на 3 |
| `17` | `true\n` | Не делится на 3, но оканчивается на 7 |
| `10` | `false\n` | Ни одно условие не выполнено |
| `21` | `true\n` | Делится на 3 |
| `0` | `true\n` | `0 % 3 == 0` — ноль делится на 3 |
| `7` | `true\n` | Оканчивается на 7 |

## Крайние случаи

- **Ноль** — делится на любое число, кроме себя: `0 % 3 == 0` истинно.
- **Число 7** — подходит по второму условию.
- **Число 37** — подходит по второму условию, хотя на 3 не делится.
- **Число 27** — подходит по обоим условиям; результат всё равно `true`.

Вывод — строго `true` или `false` маленькими буквами, с переносом строки.
