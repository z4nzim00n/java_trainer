## JAVA_03_04. Ловушка целочисленного деления

### Задание
| Java_03_04 ||
| ------ | ------- |
| **Темы:** | Целочисленное деление, приведение типов к `double`, `printf`, `Locale.US`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает два целых числа `a` и `b` (через пробел или с новой строки) и выводит их **среднее арифметическое** с ровно двумя знаками после десятичной точки и переносом строки в конце.

```text
(a + b) / 2
```

Осторожно: здесь спрятана классическая ловушка. Если написать `(a + b) / 2`, Java выполнит **целочисленное** деление и отбросит дробную часть: для `3` и `4` получится `3`, а не `3.5`. Нужно, чтобы хотя бы один операнд был `double`:

```java
double avg = (a + b) / 2.0;
```

Вывод:

```java
System.out.printf(Locale.US, "%.2f\n", avg);
```

Не забудь `sc.useLocale(Locale.US)` после создания `Scanner`, чтобы числа читались и печатались с точкой.

Гарантируется, что на вход подаются два корректных целых числа.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3 4 | 3.50 |
| 1 2 | 1.50 |
| -3 4 | 0.50 |
| 5 5 | 5.00 |
