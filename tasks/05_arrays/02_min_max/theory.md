# Разбор задания

## Массив в Java

```java
int[] a = new int[n];   // массив из n целых, по умолчанию заполнен нулями
a[0] = 10;              // индексы от 0 до n - 1
```

Размер массива фиксируется при создании и хранится в поле `a.length`. Выход за границы (`a[n]`) — исключение `ArrayIndexOutOfBoundsException` во время выполнения.

## Два экстремума за один проход

Не нужно сортировать массив, чтобы найти минимум и максимум. Достаточно одного прохода:

```java
int min = a[0];
int max = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] < min) min = a[i];
    if (a[i] > max) max = a[i];
}
```

Сложность O(N), память O(1) сверх самого массива.

## Почему не a[0] = 0

Тот же аргумент, что и в задаче на максимум последовательности: `0` может оказаться больше или меньше всех настоящих элементов. Единственное гарантированно существующее значение — `a[0]`.

## Формат вывода

```java
System.out.println(min + " " + max);
```

`min + " "` — конкатенация числа и строки; Java автоматически превращает `int` в строку. Получается ровно `минимум`, пробел, `максимум`, перевод строки.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `min = 0` | Неверно для массива из положительных чисел |
| `min = Integer.MAX_VALUE` без проверки | Работает, но менее наглядно |
| `max = a[n]` | Выход за границу массива |
| `for (i = 0; i <= n; i++)` | `ArrayIndexOutOfBoundsException` |
| Печать с `print` без `\n` | Нет переноса в конце — тест не пройден |
