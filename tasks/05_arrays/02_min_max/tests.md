# JAVA_05_02. Минимум и максимум — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `5` + `3 -1 7 2 7` | `-1 7\n` | Минимум −1, максимум 7 |
| `1` + `5` | `5 5\n` | Единственный элемент — оба экстремума |
| `4` + `-9 -1 -7 -3` | `-9 -1\n` | Все числа отрицательные |
| `3` + `0 0 0` | `0 0\n` | Все равны |

## Крайние случаи

- **N = 1** — минимум и максимум совпадают.
- **Все отрицательные** — ловит `min = 0`.
- **Все равны** — оба сравнения строгие, ответ не меняется.
- **Порядок не важен** — проход не зависит от расположения экстремумов.
