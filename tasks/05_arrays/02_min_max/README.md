## JAVA_05_02. Минимум и максимум

### Задание
| Java_05_02 ||
| ------ | ------- |
| **Темы:** | Массивы `int[]`, цикл `for`, поиск минимума и максимума за один проход. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Сначала подаётся целое число `N` — размер массива, затем `N` целых чисел. Найди **минимум** и **максимум** и выведи их через пробел на одной строке с переносом в конце:

```text
<минимум> <максимум>
```

Считай числа в массив `int[]`, а затем пройди по нему один раз, поддерживая два текущих значения:

```java
int min = a[0];
int max = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] < min) min = a[i];
    if (a[i] > max) max = a[i];
}
```

Инициализация первым элементом важна: все числа могут быть отрицательными.

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>3 -1 7 2 7 | -1 7 |
| 1<br>5 | 5 5 |
| 4<br>-9 -1 -7 -3 | -9 -1 |
