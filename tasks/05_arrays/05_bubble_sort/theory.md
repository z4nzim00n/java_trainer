# Разбор задания

## Как работает пузырёк

На каждом проходе сравниваются соседние пары `(a[j], a[j+1])`. Если порядок неправильный, они меняются местами. Большие элементы постепенно «всплывают» к концу.

Пример `5 1 4 2`:

```text
5 1 4 2  →  1 5 4 2  →  1 4 5 2  →  1 4 2 5
1 4 2 5  →  1 4 2 5  →  1 2 4 5  →  1 2 4 5
```

## Зачем n - 1 - i

После `i`-го прохода последние `i` элементов уже стоят на своих местах. Поэтому внутренний цикл можно не доводить до конца: граница `n - 1 - i` экономит сравнения.

## Внешний цикл n - 1

Один элемент (минимальный) встаёт на место автоматически, когда все остальные уже отсортированы, поэтому достаточно `n - 1` проходов. Для `n = 1` циклы не выполняются вовсе.

## Обмен

Снова нужна временная переменная:

```java
int tmp = a[j];
a[j] = a[j + 1];
a[j + 1] = tmp;
```

## Сложность и устойчивость

- Время: O(N²) в среднем и худшем случае, O(N) в лучшем (с флагом `swapped`).
- Память: O(1).
- Алгоритм **устойчив**: равные элементы не меняют относительного порядка, потому что обмен выполняется только при строгом `>`.

Модификация с флагом:

```java
boolean swapped = true;
for (int i = 0; i < n - 1 && swapped; i++) {
    swapped = false;
    ...
            swapped = true;
}
```

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `j < n` | `a[j + 1]` выходит за границу |
| `a[j] >= a[j + 1]` | Лишние обмены равных (неустойчивость), ответ тот же |
| Забыть временную переменную | Элементы затираются |
| Внешний цикл до `n` | Лишний проход, не ошибка, но медленнее |
| `Arrays.sort(a)` | Задача про реализацию сортировки |
