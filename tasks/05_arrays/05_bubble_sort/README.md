## JAVA_05_05. Пузырьковая сортировка

### Задание
| Java_05_05 ||
| ------ | ------- |
| **Темы:** | Сортировка массива, вложенные циклы, обмен элементов, сложность O(N²). |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Сначала подаётся `N` — размер массива, затем `N` целых чисел. Отсортируй массив **по возрастанию** алгоритмом пузырьковой сортировки и выведи элементы через пробел в одной строке.

Идея пузырька: многократно проходим по массиву, сравниваем соседние элементы и меняем их, если левый больше правого. После каждого прохода самый большой элемент «всплывает» в конец.

```java
for (int i = 0; i < n - 1; i++) {
    for (int j = 0; j < n - 1 - i; j++) {
        if (a[j] > a[j + 1]) {
            int tmp = a[j];
            a[j] = a[j + 1];
            a[j + 1] = tmp;
        }
    }
}
```

Использовать `Arrays.sort` нельзя — цель задания написать сортировку самостоятельно.

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>5 1 4 2 8 | 1 2 4 5 8 |
| 1<br>0 | 0 |
| 4<br>9 9 1 1 | 1 1 9 9 |
| 3<br>-1 3 -5 | -5 -1 3 |
