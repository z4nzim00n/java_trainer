## JAVA_05_01. Сумма и среднее массива

### Задание
| Java_05_01 ||
| ------ | ------- |
| **Темы:** | Одномерные массивы, `int[]`, цикл `for`, накопление суммы, приведение типов, `printf`, `Locale.US`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу с нуля. Сначала подаётся целое число `N` — размер массива, затем `N` целых чисел — его элементы. Числа могут разделяться пробелами или переносами строк.

Посчитай **сумму** всех элементов и их **среднее арифметическое**. Выведи два числа на двух строках:

```text
<сумма>
<среднее>
```

Сумма — целое число. Среднее выведи **ровно с двумя знаками после точки** и переносом строки в конце:

```java
System.out.println(sum);
System.out.printf(Locale.US, "%.2f\n", avg);
```

Чтобы среднее не обрезалось до целого, дели в типе `double`: `(double) sum / n`. Для вывода с точкой используй `Locale.US` (и `sc.useLocale(Locale.US)` после создания `Scanner`).

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3<br>1 2 3 | 6<br>2.00 |
| 4<br>10 20 30 40 | 100<br>25.00 |
| 1<br>5 | 5<br>5.00 |
