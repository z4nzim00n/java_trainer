## Проверка вывода

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `3\n1 2 3` | `6\n2.00\n` | `printf '3\n1 2 3\n' \| java Main` | сумма 6, среднее 6/3 = 2.00 |
| `4\n10 20 30 40` | `100\n25.00\n` | `printf '4\n10 20 30 40\n' \| java Main` | сумма 100, среднее 100/4 = 25.00 |
| `1\n5` | `5\n5.00\n` | `printf '1\n5\n' \| java Main` | один элемент: сумма = среднее = 5 |

## Крайние случаи

- **N = 1** — массив из одного элемента: сумма и среднее совпадают, но среднее всё равно печатается с двумя знаками (`5.00`).
- **Целочисленное деление** — если среднее не целое (например, сумма 7 при n = 2 → 3.5), без приведения `(double)` ответ был бы错误的 `3.00`. Проверяй: `printf '2\n3 4\n' | java Main` → `7\n3.50\n`.
- **Отрицательные числа** — сумма может быть отрицательной, формат `%.2f` печатает знак: `printf '2\n-3 -4\n' | java Main` → `-7\n-3.50\n`.
- **Пробелы вместо переносов** — `nextInt` не различает пробелы и `\n`, поэтому `3 1 2 3` работает так же, как `3\n1 2 3`.
- **EOF без `\n`** — `Scanner` дочитывает последнее число и без завершающего переноса.

## Как увидеть точные байты

```bash
printf '3\n1 2 3\n' | java Main | od -An -t x1
```

Ожидаемые байты: `36 0a 32 2e 30 30 0a` — это `6`, `\n`, `2.00`, `\n`. Байт `2e` — точка: если там `2c` (запятая), значит забыт `Locale.US`.
