# Разбор задания

## Массивы в Java

В C ты объявлял массив как `int a[10];`. В Java массив — это **объект**, который создаётся оператором `new` и знает свою длину:

```java
int[] a = new int[n];   // массив из n целых, все элементы изначально 0
```

| Запись | Что означает |
| --- | --- |
| `int[] a` | переменная `a` — ссылка на массив целых (`int`) |
| `new int[n]` | выделить память под `n` элементов, заполнить нулями |
| `a[i]` | элемент с индексом `i`, индексы от `0` до `n-1` |
| `a.length` | длина массива (поле, **без скобок** — это не метод) |

Размер массива в Java нельзя изменить после создания. Если нужно больше места — создают новый массив.

## Чтение массива с ввода

Сначала читаем размер, затем в цикле заполняем элементы:

```java
int n = sc.nextInt();
int[] a = new int[n];
for (int i = 0; i < n; i++) {
    a[i] = sc.nextInt();
}
```

`nextInt()` читает целые числа, пропуская любые пробелы и переносы строк. Поэтому вход `3 1 2 3` и `3\n1 2 3\n` разбираются одинаково.

## Накопление суммы

Классический приём — переменная-накопитель, initialised нулём, и проход по массиву:

```java
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i];   // то же самое, что sum = sum + a[i];
}
```

## Ловушка целочисленного деления

Среднее — это сумма, делённая на количество. Но `sum` и `n` — целые (`int`), поэтому `sum / n` в Java (как и в C) даёт **целое** с отбрасыванием дробной части:

| Выражение | Результат | Почему |
| --- | --- | --- |
| `6 / 4` | `1` | целочисленное деление |
| `(double) 6 / 4` | `1.5` | привели 6 к double → деление вещественное |
| `6 / 4.0` | `1.5` | один операнд double → всё выражение double |

Правильно: `double avg = (double) sum / n;`. Приведение `(double)` применяется к `sum` **до** деления.

## Вывод среднего с двумя знаками

```java
System.out.println(sum);                      // целое + перенос строки
System.out.printf(Locale.US, "%.2f\n", avg);  // два знака после точки + перенос
```

`%.2f` — формат «ровно 2 знака после десятичной точки, с округлением». `Locale.US` гарантирует точку (на русской Windows без него была бы запятая). Не забудь `import java.util.Locale;`.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `int[] a = new int(n);` | Круглые скобки вместо квадратных — ошибка компиляции |
| `a[n]` в цикле `i <= n` | Выход за границы: `ArrayIndexOutOfBoundsException` |
| `double avg = sum / n;` | Целочисленное деление: дробная часть теряется ДО присваивания |
| `printf("%.2f", avg)` без `\n` | Нет переноса строки в конце — тест не пройден |
| Нет `Locale.US` | На русской Windows вывод с запятой (`2,00`) — тест не пройден |
| `a.length()` | `length` у массива — поле, а не метод: скобки не нужны |
