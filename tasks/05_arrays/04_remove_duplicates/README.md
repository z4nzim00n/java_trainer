## JAVA_05_04. Убрать дубликаты

### Задание
| Java_05_04 ||
| ------ | ------- |
| **Темы:** | Массивы, вложенные циклы, порядок первого появления. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Сначала подаётся `N` — размер массива, затем `N` целых чисел. Выведи элементы **без повторов**, сохранив порядок их **первого появления**, через пробел в одной строке.

Пример: `1 2 1 3 2 4` → `1 2 3 4`.

Реши задачу на массивах, без коллекций: элемент `a[i]` выводится, только если он ещё не встречался среди `a[0] .. a[i-1]`.

```java
for (int i = 0; i < n; i++) {
    boolean seen = false;
    for (int j = 0; j < i; j++) {
        if (a[j] == a[i]) {
            seen = true;
            break;
        }
    }
    if (!seen) {
        // вывести a[i]
    }
}
```

Собирай вывод в `StringBuilder`, чтобы не ставить лишний пробел в конце.

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 6<br>1 2 1 3 2 4 | 1 2 3 4 |
| 3<br>5 5 5 | 5 |
| 1<br>-7 | -7 |
