# Разбор задания

## Идея

«Первый раз встретился» — значит, до текущей позиции такого значения не было. Проверяем это вложенным циклом по уже просмотренной части массива.

```java
boolean seen = false;
for (int j = 0; j < i; j++) {
    if (a[j] == a[i]) {
        seen = true;
        break;
    }
}
```

`break` прерывает внутренний цикл, как только найден повтор — дальше проверять незачем.

## Сложность

Вложенные циклы дают O(N²) сравнений в худшем случае (все элементы различны). Для учебного массива это нормально. В разделе коллекций та же задача решается через `LinkedHashSet` за O(N), но здесь важно потренировать индексы.

## Почему не сортировка

Сортировка уничтожила бы порядок первого появления: `1 2 1 3` после сортировки `1 1 2 3` всё ещё даст `1 2 3`, но для `3 1 3 2` порядок `3 1 2` уже нельзя восстановить из отсортированного массива. Поэтому проверка «был ли раньше» — правильный подход.

## Сборка строки

```java
StringBuilder sb = new StringBuilder();
...
if (sb.length() > 0) {
    sb.append(' ');
}
sb.append(a[i]);
```

Проверка `length() > 0` гарантирует, что пробел ставится только **перед** элементом, а не после. В конце — `System.out.println(sb)`, который сам добавит `\n`.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| Сравнивать с `a[j]` при `j <= i` | Элемент всегда «встречался» — пустой вывод |
| Нет `break` | Лишние сравнения, но результат верный |
| Пробел после каждого элемента | Лишний пробел в конце — тест не пройден |
| Сортировать массив | Теряется порядок первого появления |
| `seen = false` вне цикла `i` | Флаг не сбрасывается между элементами |
