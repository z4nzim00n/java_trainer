# JAVA_05_04. Убрать дубликаты — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `6` + `1 2 1 3 2 4` | `1 2 3 4\n` | Повторы 1 и 2 убраны |
| `3` + `5 5 5` | `5\n` | Остаётся одно значение |
| `1` + `-7` | `-7\n` | Один элемент |
| `4` + `3 1 3 2` | `3 1 2\n` | Порядок первого появления |
| `5` + `0 -1 0 -1 0` | `0 -1\n` | Ноль и отрицательное |

## Крайние случаи

- **Все элементы одинаковы** — в выводе ровно одно число.
- **Порядок** — `3 1 3 2` даёт `3 1 2`, а не отсортированное `1 2 3`.
- **Отрицательные числа и ноль** — сравнение `==` работает одинаково.
- **Нет дубликатов** — массив выводится целиком.
