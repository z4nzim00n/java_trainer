# Разбор задания

## Индексы массива

Элементы нумеруются с нуля: у массива длины `n` допустимы индексы `0 .. n - 1`. Пара `left = 0`, `right = n - 1` указывает на края.

## Обмен значений

Попытка «поменять местами» без временной переменной:

```java
a[left] = a[right];   // старое a[left] потеряно
a[right] = a[left];   // записываем то же самое значение
```

Нужна третья переменная:

```java
int tmp = a[left];
a[left] = a[right];
a[right] = tmp;
```

## Алгоритм двух указателей

1. `left` смотрит на начало, `right` — на конец.
2. Меняем элементы местами.
3. Сдвигаем указатели навстречу друг другу.
4. Останавливаемся, когда `left >= right` — середина пройдена.

Для нечётной длины центральный элемент остаётся на месте сам, поэтому дополнительная проверка не нужна.

## Сложность

- Время: O(N/2) = O(N) — обменов примерно половина длины.
- Дополнительная память: O(1) — только `tmp`.

Альтернатива — печатать массив с конца, не меняя его:

```java
for (int i = n - 1; i >= 0; i--) { ... }
```

Но задание требует развернуть массив на месте, поэтому нужен обмен.

## Вывод с пробелами

Чтобы не было лишнего пробела в конце, удобно собирать строку:

```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < n; i++) {
    if (i > 0) sb.append(' ');
    sb.append(a[i]);
}
System.out.println(sb);
```

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| Обмен без `tmp` | Оба элемента становятся одинаковыми |
| `while (left <= right)` | Для чётной длины лишний обмен середины |
| Забыть `left++`/`right--` | Бесконечный цикл |
| Создать второй массив | Нарушает условие «на месте» |
| Печать с лишним пробелом | Побайтовое сравнение не пройдёт |
