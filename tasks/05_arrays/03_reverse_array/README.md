## JAVA_05_03. Развернуть массив

### Задание
| Java_05_03 ||
| ------ | ------- |
| **Темы:** | Массивы, индексы, обмен двух элементов, два указателя. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Сначала подаётся `N` — размер массива, затем `N` целых чисел. **Разверни массив на месте** (без создания второго массива) и выведи его элементы через пробел в одной строке с переносом в конце.

Приём с двумя индексами:

```java
int left = 0;
int right = n - 1;
while (left < right) {
    int tmp = a[left];
    a[left] = a[right];
    a[right] = tmp;
    left++;
    right--;
}
```

Обмен двух значений в Java нельзя записать как `a[left] = a[right]; a[right] = a[left];` — первое присваивание затрёт значение. Нужна временная переменная (или XOR-трюк, но он здесь только запутывает).

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>1 2 3 4 5 | 5 4 3 2 1 |
| 1<br>7 | 7 |
| 3<br>-1 0 1 | 1 0 -1 |
