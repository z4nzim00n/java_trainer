# JAVA_05_03. Развернуть массив — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `5` + `1 2 3 4 5` | `5 4 3 2 1\n` | Нечётная длина |
| `1` + `7` | `7\n` | Один элемент |
| `3` + `-1 0 1` | `1 0 -1\n` | Отрицательные числа |
| `4` + `1 2 3 4` | `4 3 2 1\n` | Чётная длина |
| `2` + `8 9` | `9 8\n` | Минимальная чётная длина |

## Крайние случаи

- **N = 1** — обмен не нужен, `left == right`.
- **Чётная длина** — граница `left < right` останавливает вовремя.
- **Все элементы равны** — результат неотличим от входа, но обмен корректен.
- **Пробелы** — между числами ровно один пробел, в конце строки пробела нет.
