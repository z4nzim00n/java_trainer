# JAVA_05_06. Поменять максимум и минимум — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `5` + `3 9 1 7 2` | `3 1 9 7 2\n` | 9 (индекс 1) и 1 (индекс 2) меняются |
| `5` + `-3 -9 -1 -9 -3` | `-3 -1 -9 -9 -3\n` | Первый минимум −9 и максимум −1 |
| `3` + `7 7 7` | `7 7 7\n` | Все равны, индексы совпадают |
| `2` + `1 9` | `9 1\n` | Минимум слева, максимум справа |

## Крайние случаи

- **Все элементы равны** — `minIndex == maxIndex`, массив не меняется.
- **Повторы минимума** — меняется **первый** из них.
- **Повторы максимума** — меняется **первый** из них.
- **Максимум левее минимума** — обмен через индексы работает в любую сторону.
