## JAVA_05_06. Поменять максимум и минимум

### Задание
| Java_05_06 ||
| ------ | ------- |
| **Темы:** | Массивы, поиск индексов, обмен элементов, крайние случаи. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Сначала подаётся `N` — размер массива, затем `N` целых чисел. Поменяй местами **первый максимум** и **первый минимум** и выведи получившийся массив через пробел в одной строке.

Нужно запоминать именно **индексы**, а не значения:

```java
int minIndex = 0;
int maxIndex = 0;
for (int i = 1; i < n; i++) {
    if (a[i] < a[minIndex]) minIndex = i;
    if (a[i] > a[maxIndex]) maxIndex = i;
}
int tmp = a[minIndex];
a[minIndex] = a[maxIndex];
a[maxIndex] = tmp;
```

Строгие сравнения `<` и `>` обеспечивают выбор **первого** минимума и максимума при повторах.

Если все элементы равны, `minIndex == maxIndex`, и обмен элемента с самим собой ничего не меняет — это корректный случай, отдельная проверка не нужна (хотя она не помешает).

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>3 9 1 7 2 | 3 1 9 7 2 |
| 5<br>-3 -9 -1 -9 -3 | -3 -1 -9 -9 -3 |
| 3<br>7 7 7 | 7 7 7 |
