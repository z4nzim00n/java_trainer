# JAVA_04_04. Произведение нечётных цифр — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `1235` | `15\n` | Нечётные 1, 3, 5 → 1·3·5 |
| `2468` | `0\n` | Нечётных цифр нет — флаг не сработал |
| `0` | `0\n` | Ноль чётный, нечётных цифр нет |
| `13579` | `945\n` | 1·3·5·7·9 |
| `222222222` | `0\n` | Все цифры чётные |

## Крайние случаи

- **Все цифры чётные** — ключевой тест на флаг `found`: без него получится `1`.
- **Ноль** — тоже «нет нечётных цифр», ответ `0`.
- **Только чётные и одна нечётная** (`2461`) — ответ `1`.
- **Длинное число из девяток** — проверяет, что `long` достаточно.
