## JAVA_04_04. Произведение нечётных цифр

### Задание
| Java_04_04 ||
| ------ | ------- |
| **Темы:** | Цикл `while`, разбор на цифры, `long`, флаг `boolean`. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает одно неотрицательное целое число и выводит **произведение всех его нечётных цифр**. Если нечётных цифр нет, выведи `0`. В конце — перенос строки.

Цифра нечётная, если `digit % 2 == 1` (единица тоже нечётная).

Здесь есть тонкость: произведение надо накапливать в переменной, начальное значение которой — `1` (нейтральный элемент умножения). Но если нечётных цифр вообще не встретилось, ответом должен быть `0`, а не `1`. Поэтому нужен флаг:

```java
long product = 1;
boolean found = false;
while (n > 0) {
    int digit = n % 10;
    if (digit % 2 == 1) {
        product *= digit;
        found = true;
    }
    n /= 10;
}
System.out.println(found ? product : 0);
```

Произведение храни в `long`: у числа из десяти девяток результат не помещается в `int`.

Гарантируется, что `0 <= n <= 2 000 000 000`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 1235 | 15 |
| 2468 | 0 |
| 0 | 0 |
| 13579 | 945 |
