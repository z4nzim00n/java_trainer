# JAVA_04_06. Непарное число — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `5` + `1 2 3 2 1` | `3\n` | Пары 1 и 2 гасятся |
| `3` + `4 4 -7` | `-7\n` | Отрицательное непарное |
| `1` + `42` | `42\n` | Единственное число и есть непарное |
| `7` + `0 0 9 9 5 5 8` | `8\n` | Непарное в конце |

## Крайние случаи

- **N = 1** — цикл выполняется один раз, `0 ^ x = x`.
- **Отрицательное непарное** — проверяет, что XOR работает и с отрицательными.
- **Ноль как непарное** (`3` + `0 1 1`) — ответ `0`, и это правильный ответ, а не «пусто».
- **Непарное в начале, середине или конце** — порядок не влияет.
