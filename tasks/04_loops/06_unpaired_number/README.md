## JAVA_04_06. Непарное число

### Задание
| Java_04_06 ||
| ------ | ------- |
| **Темы:** | Побитовое исключающее ИЛИ `^`, свойства XOR, цикл. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Это задача из вводного дня Java Bootcamp Школы 21.

Подаётся `N` целых чисел. Каждое число встречается **ровно два раза**, кроме одного — оно встречается один раз. Найди и выведи это число. В конце — перенос строки.

Сначала подаётся количество чисел `N`, затем сами числа.

Эту задачу можно решить без массивов и коллекций — с помощью побитового XOR (`^`):

```java
int result = 0;
for (int i = 0; i < n; i++) {
    result ^= sc.nextInt();
}
System.out.println(result);
```

Свойства, на которых всё держится:

- `x ^ x = 0` — одинаковые числа «гасят» друг друга;
- `x ^ 0 = x` — ноль нейтрален;
- `a ^ b = b ^ a` — порядок не важен.

Парные числа взаимно уничтожаются, и остаётся только непарное.

Гарантируется, что `N` нечётно и все числа помещаются в `int`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>1 2 3 2 1 | 3 |
| 3<br>4 4 -7 | -7 |
| 1<br>42 | 42 |
