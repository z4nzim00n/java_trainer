# JAVA_04_01. Максимум последовательности — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон и комментарии — отдельными файлами:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `5` + `3 -1 7 2 7` | `7\n` | Максимум 7 встречается дважды |
| `1` + `-42` | `-42\n` | Единственный элемент |
| `3` + `5 5 5` | `5\n` | Все числа равны |
| `4` + `-9 -1 -7 -3` | `-1\n` | Все числа отрицательные |

## Крайние случаи

- **N = 1** — цикл не выполняется ни разу, ответ — единственное число.
- **Все числа отрицательные** — именно здесь ломается `max = 0`.
- **Максимум в конце** — проверяет, что обновление работает на любой позиции.
- **Повторяющиеся значения** — на ответ не влияют.

## Как увидеть точные байты

```bash
printf '3\n5 5 5\n' | java Main | od -An -t x1
```

Ожидаемые байты: `35 0a` — цифра `5` и перенос строки.
