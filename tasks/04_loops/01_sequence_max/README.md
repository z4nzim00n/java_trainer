## JAVA_04_01. Максимум последовательности

### Задание
| Java_04_01 ||
| ------ | ------- |
| **Темы:** | Цикл `for`, чтение последовательности, поиск максимума. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая находит **наибольшее** число в последовательности.

Сначала подаётся целое число `N` — количество чисел (`N >= 1`), затем `N` целых чисел. Числа могут разделяться пробелами или переносами строк. Выведи максимум и перенос строки в конце.

Правильный приём: считать первое число и взять его за текущий максимум, а затем в цикле читать оставшиеся `N - 1` чисел и обновлять максимум, если встретилось большее.

```java
int max = sc.nextInt();
for (int i = 1; i < n; i++) {
    int value = sc.nextInt();
    if (value > max) {
        max = value;
    }
}
```

Не инициализируй максимум нулём: все числа могут быть отрицательными, и тогда ответ будет неверным.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>3 -1 7 2 7 | 7 |
| 1<br>-42 | -42 |
| 3<br>5 5 5 | 5 |
