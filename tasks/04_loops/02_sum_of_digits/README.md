## JAVA_04_02. Сумма цифр

### Задание
| Java_04_02 ||
| ------ | ------- |
| **Темы:** | Цикл `while`, `% 10`, `/ 10`, обработка нуля. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает одно неотрицательное целое число и выводит **сумму его цифр** с переносом строки в конце.

Идея: последняя цифра числа — это `n % 10`, а отбросить её можно делением `n / 10`. Повторяй, пока число не станет нулём:

```java
int n = sc.nextInt();
int sum = 0;
while (n > 0) {
    sum += n % 10;
    n /= 10;
}
```

Для числа `0` цикл не выполнится ни разу, и сумма останется равной `0` — это правильный ответ.

Гарантируется, что `0 <= n <= 2 000 000 000`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 12345 | 15 |
| 0 | 0 |
| 9999 | 36 |
| 7 | 7 |
