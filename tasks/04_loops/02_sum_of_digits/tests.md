# JAVA_04_02. Сумма цифр — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `12345` | `15\n` | 1+2+3+4+5 |
| `0` | `0\n` | Цикл не выполняется ни разу |
| `9999` | `36\n` | 9·4 |
| `7` | `7\n` | Однозначное число |
| `1000` | `1\n` | Нули не влияют на сумму |

## Крайние случаи

- **Ноль** — важнейший тест: проверяет, что цикл не выполнится и сумма останется нулём.
- **Число с нулями внутри** (`1000`, `2050`) — нули добавляют `0`, но не ломают разбор.
- **Максимум `int`-диапазона** (`2 000 000 000`) — сумма `2`, всё помещается в `int`.
