# Разбор задания

## Разбор числа на цифры

Тот же приём, что и в сумме цифр:

```java
int digit = n % 10;  // последняя цифра
n /= 10;             // отбросить её
```

Например, для `2739`: получаем цифры `9`, `3`, `7`, `2` — в обратном порядке. Для поиска максимума порядок не важен.

## Максимум среди цифр

Цифры всегда лежат в диапазоне `0..9`, поэтому начальное значение `0` безопасно: оно не больше любой настоящей цифры. Это отличие от поиска максимума в произвольном массиве, где ноль мог бы оказаться больше всех элементов.

```java
int max = 0;
while (n > 0) {
    int digit = n % 10;
    if (digit > max) {
        max = digit;
    }
    n /= 10;
}
```

## Что происходит с нулём

Для `n = 0` цикл не выполняется, `max` остаётся `0`. Это правильный ответ: наибольшая цифра нуля — `0`.

Для числа вроде `1000` цифры `0`, `0`, `0`, `1`: максимум станет `1`, потому что `1 > 0`.

## Порядок цифр

Так как `n % 10` выдаёт цифры справа налево, максимум находится независимо от порядка. Если бы задача требовала, например, «первую максимальную цифру слева», пришлось бы сначала развернуть число.

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| `max = n % 10` внутри цикла без сравнения | Максимумом становится последняя цифра |
| Забыть `n /= 10` | Бесконечный цикл |
| Сравнивать `digit < max` | Ищется минимум |
| Инициализировать `max = 9` | Ответ всегда 9 |
| `while (n >= 0)` | Бесконечный цикл |
