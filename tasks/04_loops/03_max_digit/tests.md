# JAVA_04_03. Максимальная цифра — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `2739` | `9\n` | 9 — наибольшая цифра |
| `0` | `0\n` | Единственная цифра |
| `1111` | `1\n` | Все цифры равны |
| `907` | `9\n` | Максимум в начале числа |
| `1234567890` | `9\n` | Все цифры различны |

## Крайние случаи

- **Ноль** — цикл не выполняется, ответ `0`.
- **Нули внутри числа** — не влияют на максимум.
- **Повторяющиеся цифры** — сравнение строгое, но ответ тот же.
- **Максимум в любой позиции** — порядок разбора не важен.
