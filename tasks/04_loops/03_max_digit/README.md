## JAVA_04_03. Максимальная цифра

### Задание
| Java_04_03 ||
| ------ | ------- |
| **Темы:** | Цикл `while`, разбор числа на цифры, максимум. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает одно неотрицательное целое число и выводит его **наибольшую цифру** с переносом строки в конце.

Разбирай число так же, как в задаче про сумму цифр: `n % 10` — последняя цифра, `n / 10` — остаток числа. В цикле сравнивай очередную цифру с текущим максимумом.

```java
int max = 0;
while (n > 0) {
    int digit = n % 10;
    if (digit > max) {
        max = digit;
    }
    n /= 10;
}
```

Для числа `0` цикл не выполнится, и ответ будет `0` — это верно, ведь единственная цифра нуля и есть `0`.

Гарантируется, что `0 <= n <= 2 000 000 000`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2739 | 9 |
| 0 | 0 |
| 1111 | 1 |
| 907 | 9 |
