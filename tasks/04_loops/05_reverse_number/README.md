## JAVA_04_05. Развернуть число

### Задание
| Java_04_05 ||
| ------ | ------- |
| **Темы:** | Цикл `while`, `% 10`, `/ 10`, `long`, сборка числа. |
| **Файл решения:** | Main.java |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Напиши программу, которая считывает одно неотрицательное целое число и выводит его **в обратном порядке цифр**, без ведущих нулей, с переносом строки в конце.

Например, `12340` превращается в `4321`: ноль оказался ведущим и исчез, потому что это число, а не строка.

Собирай результат по одной цифре:

```java
long reversed = 0;
while (n > 0) {
    reversed = reversed * 10 + n % 10;
    n /= 10;
}
```

`reversed * 10` сдвигает уже собранные цифры влево, а `+ n % 10` добавляет новую цифру справа.

Для числа `0` цикл не выполнится, и ответ будет `0`.

Гарантируется, что `0 <= n <= 2 000 000 000`. Результат может не помещаться в `int`, поэтому используй `long`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 12340 | 4321 |
| 0 | 0 |
| 100 | 1 |
| 7 | 7 |
