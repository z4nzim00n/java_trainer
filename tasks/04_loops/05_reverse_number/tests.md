# JAVA_04_05. Развернуть число — Тесты

## Компиляция

```bash
javac -encoding UTF-8 Main.java
java Main
```

Эталон:

```bash
javac -encoding UTF-8 Solution.java && java Solution
javac -encoding UTF-8 SolutionCommented.java && java SolutionCommented
```

## Проверка вывода

| Вход | Результат | Пояснение |
| --- | --- | --- |
| `12340` | `4321\n` | Ведущий ноль исчезает |
| `0` | `0\n` | Цикл не выполняется |
| `100` | `1\n` | Два ведущих нуля |
| `7` | `7\n` | Однозначное число |
| `123456789` | `987654321\n` | Все цифры различны |

## Крайние случаи

- **Нули в конце** — проверяют, что результат — число, а не строка.
- **Ноль** — особый случай, но цикл `while` обрабатывает его естественно.
- **Число с переполнением при развороте** — например, `1234567899`: ответ `9987654321` требует `long`.
- **Палиндром** (`12321`) — разворот совпадает с исходным.
