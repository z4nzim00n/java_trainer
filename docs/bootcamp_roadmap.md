# Java Bootcamp: карта тем и продолжение обучения

Java Bootcamp Школы 21 состоит из дней Day00–Day09 и двух командных проектов
(Team00 — Maven, Team01 — клиент-серверная игра). Тренажёр закрывает базу,
на которой эти дни держатся. Ниже — соответствие разделов тренажёра темам
Bootcamp и список того, что стоит изучать отдельно.

## Что именно даёт каждый раздел

### Day00 — база языка

Нужно уметь без подсказок:

- объявить класс с `main`, скомпилировать `javac`, запустить `java`;
- прочитать число и строку через `Scanner`, не путаясь с `nextInt`/`nextLine`;
- написать цикл, найти минимум/максимум, развернуть число;
- работать с массивом: индексы, `length`, сортировка;
- собрать строку и разбить её через `split`.

Разделы 01–06 закрывают это полностью. Если какой-то день Bootcamp кажется
тяжёлым, сначала пройди соответствующий раздел тренажёра.

### Day01 — ООП и коллекции

Раздел 07 даёт классы, конструкторы, `this`, `static`, наследование,
полиморфизм, `toString`/`equals`/`hashCode`. Раздел 08 — `ArrayList`,
`HashMap`, `HashSet`, `Deque`, `Iterator`, `Comparator`.

В Bootcamp Day01 обычно требуют свою реализацию коллекций и работу с
интерфейсами. После тренажёра стоит потренироваться отдельно:

- написать свой динамический массив (аналог `ArrayList`) с `add`, `get`,
  `remove`, `size`;
- реализовать `equals`/`hashCode` для класса с несколькими полями.

### Day02 — файлы и исключения

Раздел 09 — checked/unchecked, `try`/`catch`/`finally`, своё исключение.
Раздел 10 — `Path`, `Files`, `StandardCharsets`, `readAllLines`, `write`,
`copy`, определение формата по сигнатуре.

Что добавить самостоятельно:

- `BufferedReader`/`BufferedWriter` и `try`-с-ресурсами;
- `InputStream`/`OutputStream` и работа с бинарными файлами;
- сериализация объектов (`ObjectOutputStream`) — если она есть в конкретном
  сабжекте дня.

### Day03 — потоки

Раздел 11: `Thread`, `Runnable`, `start`/`join`, `synchronized`, `ExecutorService`,
`Future`, `InterruptedException`.

Что добавить:

- `AtomicInteger`, `volatile`, `ReentrantLock`, `CountDownLatch`,
  `BlockingQueue`;
- классические задачи: producer–consumer, dining philosophers;
- аккуратная остановка потока через флаг и `interrupt()`.

### Day04 — JAR

В тренажёре этой темы нет. Минимум, который нужно освоить:

```bash
javac -d out Main.java
jar cfe app.jar Main -C out .
java -jar app.jar
```

- `MANIFEST.MF` и строка `Main-Class`;
- `jar tf app.jar` — содержимое архива;
- запуск класса из JAR: `java -cp app.jar Main`;
- ресурсы внутри JAR читаются через `getResourceAsStream`, а не через `File`.

### Day05 — SQL и JDBC

Темы для отдельного изучения:

- SQL: `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `JOIN`, `GROUP BY`, агрегаты;
- JDBC: `DriverManager.getConnection`, `PreparedStatement`, `ResultSet`;
- `try`-с-ресурсами для `Connection`/`Statement`/`ResultSet`;
- SQL-инъекции и почему нужны параметры `?`;
- транзакции: `setAutoCommit(false)`, `commit`, `rollback`.

Мини-проект: консольный банк — таблица `accounts`, перевод между счетами
в транзакции.

### Day06 — JUnit и Mockito

В тренажёре тесты написаны на bash, потому что так проверяются консольные
программы без сборщика. В Bootcamp нужен JUnit:

- `@Test`, `@BeforeEach`, `@AfterEach`, `@BeforeAll`, `@AfterAll`;
- `assertEquals`, `assertTrue`, `assertThrows`;
- параметризованные тесты;
- Mockito: `mock`, `when`, `verify`, `@Mock`, `@InjectMocks`.

Упражнение: взять задания разделов 07–09 и написать к ним JUnit-тесты вместо
`run_tests*.sh`. Это сразу покажет разницу между тестированием вывода и
тестированием поведения классов.

### Day07 — рефлексия

Раздел 13: `Class`, `getDeclaredFields`, `getMethod`, `invoke`,
`setAccessible`, `ReflectiveOperationException`.

Что добавить:

- `Constructor.newInstance` и создание объектов без `new`;
- аннотации и их чтение через `getAnnotation`;
- `getDeclaredMethods` и поиск методов по аннотации — это ровно то, что делает
  JUnit.

### Day08 — Spring

Spring опирается на Day01, Day05 и Day07. Перед ним полезно понимать:

- интерфейсы, внедрение зависимостей, инверсию управления;
- JDBC и работу с БД;
- аннотации и рефлексию.

Минимум для старта: Spring Boot-приложение с одним REST-контроллером и
`JdbcTemplate`, затем — слои `Controller` → `Service` → `Repository`.

### Day09 — сокеты

База — раздел 11 (потоки) и раздел 10 (потоки ввода-вывода). Дальше:

- `ServerSocket`, `Socket`, `accept`, `getInputStream`/`getOutputStream`;
- протокол обмена: длина сообщения или разделитель;
- один поток на клиента либо пул потоков;
- корректное закрытие сокетов и обработка обрыва связи.

Мини-проект: консольный чат на несколько клиентов.

### Team00 — Maven

Структура проекта:

```text
pom.xml
src/main/java/...
src/test/java/...
```

- `groupId`, `artifactId`, `version`;
- зависимости и их scope (`test` для JUnit);
- `mvn compile`, `mvn test`, `mvn package`;
- `exec-maven-plugin` или `maven-shade-plugin` для запускаемого JAR.

### Team01 — клиент-серверная игра

Здесь соединяются почти все темы: ООП, коллекции, потоки, файлы, сокеты,
сборка. Полезно заранее уметь:

- проектировать протокол сообщений (текстовый или бинарный);
- держать состояние игры в потокобезопасных структурах;
- разделять серверную логику и сетевой слой;
- писать тесты на логику без сети.

## Рекомендуемый порядок

1. **Недели 1–2.** Разделы 01–06. Каждое задание: сначала сам, потом
   `SolutionCommented.java`, потом `theory.md`.
2. **Неделя 3.** Разделы 07–08. После каждого раздела — мини-проект на классы
   и коллекции.
3. **Неделя 4.** Разделы 09–10. Добавить `BufferedReader` и бинарные файлы.
4. **Неделя 5.** Раздел 11 и Day03-задачи: producer–consumer, счётчики.
5. **Неделя 6.** Раздел 13, затем JUnit/Mockito и Maven. Переписать тесты
   нескольких заданий на JUnit.
6. **Дальше.** JDBC → Spring → сокеты → Team01.

После каждого этапа полезно возвращаться к `trainer_theory_tests.html`:
99 вопросов показывают, какие темы просели.

## Как понять, что база готова

- Решаешь задания разделов 01–06 без запуска тестов и без подсматривания.
- Объясняешь разницу между `==` и `equals`, `String` и `StringBuilder`,
  checked и unchecked исключениями.
- Пишешь класс с конструктором, `equals`/`hashCode` и использованием в `HashMap`.
- Понимаешь, зачем `join()` и `synchronized`, и можешь объяснить race condition.
- Читаешь чужой код на Java 8 и не спотыкаешься о generics и анонимные классы.

Если это так — Day00–Day03 и Day07 Bootcamp будут для тебя повторением,
а оставшиеся дни можно осваивать по темам выше.
